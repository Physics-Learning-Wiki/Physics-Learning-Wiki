## 读者任务、编辑边界与关联

读者已会均值、方差、偏导和不确定度传播：先能从一组独立测量确定直线及斜率、截距协方差，再理解自由度与已知绝对方差和未知相对权尺度的差异，进而看懂回归推断。难点是从残差正交性得到解并判断方差来源，而非直接调用拟合函数。进阶者再做矩阵、非线性迭代和组合测量。导读的基础路线明确从不确定度传播到直线；保持页面 ID、目标锚点、题集及既有 URL。

- least-squares：保留铜棒原始数据、普通与绝对权比较、输入条件和关联链接；整体重写从目标函数到正规方程、解、残差方差及参数协方差的压缩段，补可复算的回归平方和分解、F 检验与均值区间/新观测预测区间的区分；把必要的协方差传播从折叠框移入主线并合并旧段，保留所有原标题锚点。后两区间是教学扩展：09 的实际 31 页仅见回归均值标准差，未见完整预测区间推导，不归因于课件。
- linear-parameters：保留满秩、无偏、QR/SVD、未知权尺度和已知绝对协方差区分；替换偏压缩的矩阵求导与参数协方差过程，补一个展开的手算并解释 $n-p$。与直线页以特例到一般法衔接。
- nonlinear-fitting：保留指数数据、初值及迭代与诊断；扩充首步雅可比、正规方程和更新计算，对比对数线性化与原量加性/乘性误差，说明非正值条件。不得把两种目标当作相同估计。
- combined-measurements：保留原六次自编观测及既有结论；先列三段和总长的标量残差，展示如何由它们组成正规方程，再引入矩阵和完整协方差，解释独立总长与相加结果不同。原有例子不是 08 的数据。
- case-studies：保留两套案例和现有脚本接口、全部已发布题目的前提及数字；合并重复解释，向直线主线链接并保留单摆、量块及有限自由度等现有结果。现有题集 published，q-000258–269 published，均不修改；扩展练习以另立 draft set 和预留新 ID 实现，先确认 ID 空闲。示例 readme 当前声称 Python 3.14 和未来版本，需按实际环境验证后更正，不能将推测写成运行记录。

### 课件疑错的独立检查

- 07 p.37–38 给出五条观测，p.38 的设计矩阵却多出第六行 $(1,6)$；与五维观测向量不能相乘。五条应为 $(1,1)$ 至 $(1,5)$，权比为 16:16:9:9:9。对应纸面矩阵必须修正而不能直接照抄。
- 08 p.42 列出残差平方和 0.00536 mm²；按其逐项残差平方相加是 **0.000536 mm²**，且其给出的标准差 0.013 mm 也与后者一致。
- 08 p.15 称平方根形式的单位权标准差「无偏估计」；在正态模型下对应的方差估计无偏，平方根通常并非无偏。
- 09 p.16 称增加实验次数、缩小横坐标取值范围会减小预测均值标准差；由同页公式，在观测数及其他条件可比较、预测位置偏离均值的情况下，减小 $S_{xx}$ 反而增大第二项，此处说法不能无条件成立。
- 09 p.27、29 将回归显著与拟合很好等同；F 检验拒绝零斜率并不证明模型线性、拟合充分或具有因果关系，失拟检验不显著也不证明模型正确。
