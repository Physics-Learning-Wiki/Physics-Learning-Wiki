# Physics-Learning-Wiki

## 项目简介
面向系统化物理学习与复习的结构化知识框架，包含基础概念、各分支学科、数学与实验支撑、计算与题库、术语与参考资源。

## 核心设计原则
- 分层：基础→进阶→综合
- 可扩展：目录与模块易增删
- 可复用：统一术语与符号规范
- 面向学习路径与自检

## 目录总体框架 (docs/)
- fundamentals 基础与通用概念
- math-tools 数学工具
- mechanics 力学
- thermodynamics 热学与统计
- electromagnetism 电磁学
- optics 光学
- modern-physics 近代物理（量子 / 原子 / 核 / 粒子 / 相对论）
- experimental 实验与测量
- computational 计算物理
- problem-bank 题库与分类
- glossary 术语与符号
- references 参考与教材
- roadmap 学习路线
- contributing 贡献指南
- structure 结构说明
