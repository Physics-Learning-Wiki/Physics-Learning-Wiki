## 计算物理与工具简介

本模块用于整理物理学习中最常用的写作、计算、仿真和绘图工具。它的目标不是把读者变成“工具收藏家”，而是帮助读者把物理想法更快地表达、验证和可视化。

## 为什么要学这一章

- 很多物理问题只有写下来、算出来、画出来之后才真正清楚。
- 计算工具可以帮助你检查推导、验证模型、处理数据和生成图像。
- 良好的写作与绘图习惯能够显著提升学习、汇报和协作效率。

## 学习前建议掌握

- 至少已经开始接触一门大学物理主线课程。
- 对函数、图像和基本文件操作有基础认识。
- 不需要一开始就会编程，但需要愿意把工具当成物理学习的一部分。

## 推荐阅读顺序

1. [LaTeX 物理写作](./latex.md)：先学会清楚地写公式、符号和推导。
2. [Python 科学计算](./python-scicomp.md)：用最常见的科学计算工具做数值实验与数据处理。
3. [模拟软件 (Mathematica/Matlab)](./simulation.md)：在更复杂的符号计算、数值计算和可视化场景中使用专业工具。
4. [绘图工具](./plotting.md)：把结果表达成清晰、可信的图像。

## 阅读这部分时要特别注意

1. 工具是为物理问题服务的，不要只学命令而忽略物理意义。
2. 任何程序或图像结果都需要和量纲、极限、已知结论相互检验。
3. 选择工具时优先考虑可复现、可分享和可维护，而不是一时方便。
4. 写代码或做图时，尽量让别人能看出你在研究什么物理问题。

## 这部分希望你获得什么能力

学完本模块的基础部分后，你应该能够：

- 用合适的工具写出规范的物理公式与笔记。
- 用脚本或软件处理简单数据、生成图像和验证模型。
- 让计算结果和物理解释保持一致，而不是把软件输出当成最终答案。
