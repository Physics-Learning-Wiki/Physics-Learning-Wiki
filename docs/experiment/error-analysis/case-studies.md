## 从一份记录走到一份结论

实验报告的核心不是把几个公式依次填数，而是让读者知道结果如何从观测、修正和模型中产生．本页完成两个案例：单摆说明直接测量和传播，铜棒说明由拟合参数推断物理量．两套数据均为 **自编教学数据**，假设用于演示方法，不是实际仪器或真实实验的性能声明．

完成后，你应能把原始记录、测量模型、输入信息、计算、预算和结果解释连成一条可复查的链．

## 案例一：单摆测重力加速度

### 被测量与教学条件

目标是根据给定地点的小振幅单摆，估计重力加速度 $g$．摆长 $l$ 指悬点到摆球质心的距离，周期 $T$ 来自连续 20 个完整周期的总时间．采用模型

$$
g=\frac{4\pi^2l}{T^2}.
$$

教学模型假设摆幅不超过 1 度，摆球可视为质点、摆线轻且不可伸长；支架稳定，阻尼与摆球尺寸效应在本例不确定度水平下可忽略．真实实验应核查这些条件，尤其不要把线长直接当成到球心的摆长．有限摆幅等修正若在目标精度下显著，必须加入模型．

### 原始记录与输入信息

十次总时间为 $40.12$、$40.08$、$40.16$、$40.10$、$40.14$、$40.06$、$40.18$、$40.10$、$40.12$、$40.14\,\mathrm s$，完整表格和手算见 [重复测量篇](repeated-measurements.md)．每次采用相同起止相位．教学条件规定如下：

| 来源      | 已有信息与处理                                                                 | 标准不确定度                                      |
| ------- | ----------------------------------------------------------------------- | ------------------------------------------- |
| 摆长示值    | $1.001\,\mathrm m$，零点偏差估计 $+0.001\,\mathrm m$，修正后 $l=1.000\,\mathrm m$． | 分项见下两行．                                     |
| 摆长分辨率   | 间隔 $d=0.001\,\mathrm m$，最近刻度舍入，量化差按均匀分布处理．                              | $d/\sqrt{12}=0.000288675\ldots\,\mathrm m$． |
| 摆长校准与修正 | 修正后仍有校准标准不确定度，按可靠正态信息处理，与分辨率独立．                                         | $0.00020\,\mathrm m$．                       |
| 计时重复性   | 观测独立稳定；显示间隔为 $0.01\,\mathrm s$，该读数效应已体现在重复散布中．                          | $u_A(\bar T)=0.000577350\ldots\,\mathrm s$． |
| 计时共同校准  | 总时间修正估计为零，标准不确定度为 $0.020\,\mathrm s$，所有十次共有，按可靠正态信息处理．                  | 换算到周期后 $u_B(T)=0.020/20=0.0010\,\mathrm s$． |

四项不同来源在本模型中互不相关．计时的共同校准分量不能再除以 $\sqrt{10}$；摆长只取一次读数的量化分量，未同时用重复散布重复计入．

### 合成与传播

由数据得 $\bar T=2.006\,\mathrm s$．合成输入标准不确定度：

$$
u(l)=\sqrt{(0.001/\sqrt{12})^2+0.00020^2}
=0.000351188\ldots\,\mathrm m,
$$

$$
u(T)=\sqrt{(0.000577350\ldots)^2+0.0010^2}
=0.001154701\ldots\,\mathrm s.
$$

代入测量模型得 $g=9.810652192\ldots\,\mathrm{m/s^2}$．灵敏系数为 $c_l=g/l$、$c_T=-2g/T$，所以

$$
u_c(g)=g\sqrt{\left(\frac{u(l)}l\right)^2
+\left(2\frac{u(T)}T\right)^2}
=0.011808303\ldots\,\mathrm{m/s^2}.
$$

### 不确定度预算与优先改进方向

下表贡献为 $|c_i|u_i$，百分比指 **输出方差份额**，不是标准不确定度的直接份额．预算中保留额外位数用于比较：

| 来源     | 对重力加速度的标准不确定度贡献/米每二次方秒 | 方差份额   |
| ------ | ---------------------- | ------ |
| 摆长分辨率  | 0.0028321              | 5.75%  |
| 摆长校准   | 0.0019621              | 2.76%  |
| 周期重复性  | 0.0056472              | 22.87% |
| 周期共同校准 | 0.0097813              | 68.61% |

因此最终标准不确定度报告为

$$
g=9.811\,\mathrm{m/s^2},\qquad
u_c(g)=0.012\,\mathrm{m/s^2}.
$$

若用 $k=2$ 报告扩展不确定度，使用未修约数值计算 $U=0.023616606\ldots\,\mathrm{m/s^2}$，最后写

$$
g=(9.811\pm0.024)\,\mathrm{m/s^2},\qquad k=2.
$$

括号中的范围表示扩展不确定度．在本例主导校准分量近似正态且评定可靠、一阶传播适用等假设下，可解释为约 95% 覆盖；这不是严格保证．脚本另输出的 t 区间仅针对重复计时均值，不能拿来替代本预算．

??? note "进阶补充：增加次数与改进方案"
    即使周期重复性项降到零，其余项仍给出约 $0.0104\,\mathrm{m/s^2}$ 的标准不确定度下限．优先核查计时校准的来源，比单纯增加重复次数更有潜力．若将一次计时的周期数从 20 增加，也必须重新检查这项校准信息是否真是与时长无关的加性分量；时基比例误差不会以同样方式降低．原始读数和灵敏系数要随新方案重算．这就是用预算指导测量，而不是假定所有分量总能被平均消除．

## 案例二：铜棒的线膨胀系数

### 记录、模型和拟合

温度为 $10$、$20$、$30$、$40$、$50$、$60\,{}^\circ\mathrm C$；对应长度及独立标准不确定度见 [直线拟合篇](least-squares.md#例题由长度斜率求线膨胀系数)．本例假设热平衡充分、温度输入的不确定度可忽略、长度已校准，且没有遗漏的共同校准分量．

模型为 $L=a+b\theta$，线膨胀系数为 $\alpha=b/a$．先用普通最小二乘认识斜率和残差，再用已知不等精度信息作加权拟合．两种结果如下，表中未完全修约是为了与脚本复算对应：

| 结果              | 普通拟合，未知共同噪声尺度            | 加权拟合，已知各点标准不确定度          |
| --------------- | ------------------------ | ------------------------ |
| 截距/毫米           | 1000.002000              | 1000.000644              |
| 斜率/毫米每开尔文       | 0.016942857              | 0.016960628              |
| 斜率标准不确定度/毫米每开尔文 | 0.000173323              | 0.000349397              |
| 线膨胀系数/每开尔文      | $1.6942823\times10^{-5}$ | $1.6960617\times10^{-5}$ |

加权结果使用了不同的输入信息，不能仅因为普通拟合的不确定度更小就宣称它更好．也不能强制直线通过坐标原点：铜棒在零摄氏度时的长度不为零．

### 参数传播与结果解释

用加权拟合的斜率、截距及协方差传播，得到

$$
\alpha=1.696\times10^{-5}\,\mathrm{K^{-1}},\qquad
u(\alpha)=0.035\times10^{-5}\,\mathrm{K^{-1}}.
$$

这里报告标准不确定度，不额外附加未经分析的置信水平．参数传播的公式与完整协方差数值见 [拟合篇](least-squares.md)．结论应附带温度范围与线性模型条件；不能把外推截距当成在零摄氏度直接量到的长度．

检查 [拟合图与残差图](least-squares.md#用残差检查模型) 后，可以说这组教学数据在给定范围内没有显示明显的弯曲证据；不能由六个点证明材料在任意温度都严格线性．若实际实验存在共同长度标尺或温标误差，应补入相关性模型再评定结果．

依赖只用于分析，不加入站点构建依赖．两个脚本分别在当前目录下的 `.tmp-error-analysis/pendulum/` 和 `.tmp-error-analysis/copper/` 输出 `results.json` 与 SVG 图，不弹出绘图窗口．也可在命令末尾添加 `--output-dir` 和自选路径．版本、数据字段和结果文件说明见 [示例说明](examples/readme.md)．编程入门可查 [Python 科学计算](../../tools/python-scicomp.md) 与 [绘图工具](../../tools/plotting.md)．

```text
Report (k=2): g = (9.811 +/- 0.024) m/s^2
Report (standard): alpha = (1.696 +/- 0.035) x 10^-5 /K
```

中间 JSON 保留额外位数，供复算与预算检查．它们不是最终报告应该照抄的全部数字．

## 一份可复查的报告应包含什么

1.  被测量、实验条件与模型，说明所求结果的适用范围．
2.  原始数据、单位、仪器及校准信息，注明异常处理与修正理由．
3.  每个输入的标准不确定度来源、分布假设及相关关系．
4.  关键计算或拟合方法、参数协方差、残差检查和不确定度预算．
5.  修约后的结果，明确标准/扩展不确定度；使用后者时说明包含因子和覆盖解释的条件．
6.  模型限制、主要贡献、可能改进的步骤，以及数据和代码入口．

若要与参考值比较，应同时考虑参考值的不确定度和可能的相关性；「与课本相差不到某百分比」不能替代上述分析．

## 有限自由度预算的贯通案例

补充一个修正后的教学长度结果 $L=20.00\,\mathrm{mm}$．十次重复均值的标准不确定度为 0.03 mm，自由度 9；独立证书修正分量为 0.04 mm，其相对不可靠度依据历史校准重复性判断为 25%，故等效自由度约 8．其他分量在本模型精度下可忽略．按 [评定篇](uncertainty-evaluation.md) 得 $u_c=0.05\,\mathrm{mm}$、$\nu_{\rm eff}=15.243902$、$k\approx2.128483$、$U=0.106424\,\mathrm{mm}$．

最终写为 $L=(20.00\pm0.11)\,\mathrm{mm}$，扩展不确定度，包含因子约 2.1285，有效自由度约 15.24；在给定独立性、可靠度与输出分布近似条件下作约 95% 覆盖解释．若证书分量实际均匀且占主导，应重新检查区间解释，不把自由度公式当万能校正．

## 比较校准中的嵌套模型

设量块长度比较的教学近似模型为

$$
l=l_s+\Delta l-l_s(\Delta t\,\delta\alpha+\alpha_s\delta t).
$$

$l_s$ 是参考量块长度，$\Delta l$ 为比较仪长度差，$\Delta t$ 为相对参考温度的共同偏离，$\delta\alpha$ 为两量块膨胀系数差，$\delta t$ 为两者温差．模型来自一阶热膨胀近似，符号由所用差值方向定义．

例：$l_s=100\,\mathrm{mm}$、$\Delta l=0.002\,\mathrm{mm}$、$\Delta t=1\,\mathrm K$、$\delta\alpha=10^{-6}\,\mathrm{K^{-1}}$、$\alpha_s=10^{-5}\,\mathrm{K^{-1}}$、$\delta t=0.1\,\mathrm K$，热修正为 -0.0002 mm，结果为 100.0018 mm．灵敏系数依输入顺序为 $1-(\Delta t\,\delta\alpha+\alpha_s\delta t)$、1、$-l_s\delta\alpha$、$-l_s\Delta t$、$-l_s\delta t$、$-l_s\alpha_s$．分别乘对应标准不确定度，再加入相关项．共用温度计或共同材料系数时不能默认独立．

例如六项独立标准不确定度依次为 0.0001 mm、0.0002 mm、0.2 K、$0.2\times10^{-6}\,\mathrm{K^{-1}}$、$0.5\times10^{-6}\,\mathrm{K^{-1}}$、0.02 K，合成约为 0.00022633 mm．应保留未修约系数；嵌套修正不是给结果再随意加一项「温度误差」．

## 真实复杂预算怎样读

讲义展示的 HUST 引力常量实验可联系原始论文 [Li 等，2018](https://doi.org/10.1038/s41586-018-0431-5) 阅读：不同测量方法的修正值与标准不确定度分开列示，几何、质量、扭丝、环境及统计贡献需要按各自测量模型解释．本页不复用论文截图或改写论文数值为自测数据．

读真实表时先核对相对单位 ppm 是否指量值比、列的是标准量还是扩展量、修正正负是否施加、各项是否独立．2 ppm 的相对标准不确定度表示 $2\times10^{-6}$，不等于 2%．若两项独立相对标准贡献为 3 和 4 ppm，总贡献为 5 ppm；它们的方差份额为 36% 和 64%，不是直接用 3/7 和 4/7．若某列已有一个总效应，不要把其细项再重复计入．核对共享来源、采用方法以及不同方法之间的共同分量后，才讨论合并与改进方向．

复杂案例统一可用 [补充复算脚本](examples/advanced-analysis.py) 与 CSV 重算．脚本不替代输入信息和物理条件的判断．
