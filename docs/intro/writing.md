## 内容编写指引

本站优先服务第一次系统学习该主题的本科生，以及已有零散基础的自学者．一篇页面应让读者完成具体的理解或操作；正文按物理知识领域唯一存储，课程与学习阶段通过路线页组织，避免平行重写同一推导．

## 总原则

| 层次 | 编辑要求                                                   |
| -- | ------------------------------------------------------ |
| 必须 | 定义、模型、符号、公式与例题一致；说明会改变结论的条件；来源可核查；主线必需信息可见；保护稳定 ID 与关联 |
| 推荐 | 根据读者困难选择对照例子、物理图像、推导旁注、预测问题、结果检查和迁移练习                  |
| 自由 | 开场方式、段落节奏、标题、语气及先例后理或先理后例的安排                           |

核心定义、定律、首次方法示范和承诺讲授的关键证明留在主线，不藏进默认折叠框．选读、答案与提示的放置以 [信息框规范](./admonitions.md) 为准；语法、标点、公式和存储以 [格式手册](./format.md) 为准．

## 动笔前确定读者任务

先用几句话说明：读者已经会什么、本页要让他独立完成什么、最容易卡住哪一步、哪些条件不能省．这份任务卡可以留在编辑记录中，无需成为正文栏目．对现有文章先阅读全文与必要相邻页，识别应保留的解释，再诊断问题．小勘误只需定位、正确依据与影响范围．

可以直接定义，也可以从现象、实验、结果或旧方法的困难开始．「为什么引入」应由具体解释承担，不强制设 Why 小节，更不能把「旧方法计算麻烦」夸成「旧理论错误」．不同组织的 [教学示例](./teaching-examples.md) 可用于比较取舍．

导读负责路线选择，速查页负责准确消歧，证明页负责恢复关键论证；它们无需共同满足一套栏目或例题数量．没有统一篇幅、标题数、配图数、问句数或每页题数要求．

## 推导、例题与练习

让读者知道数学操作作用于什么对象、哪些量固定、为什么选择这个方法．首次几何投影、积分微元、近似、变量消去和条件使某项为零的步骤需要解释；熟练代数可压缩，但应能恢复．不能为流畅删掉关键条件，也不必逐行展示普通算术．

例题须有明确题意、系统与参考系、模型条件、方法理由、求解及结果解释，可用连续叙述组织．按风险选择量纲、方向、符号、极限或另一方法核对；通过一种检查并不证明全部结论正确．

正文中的小预测可配折叠答案，不必进入题库；值得反复练习、跨页复用或保存学习记录的题目再进入正式题库．练习按能力覆盖选择，不按数量填充；不能链接尚未公开的题集并宣称立即可用．题库发布仍须真实人工签署，见 [编辑审校](./editorial-review.md)．

## 术语与译名约定

术语应帮助读者识别同一个概念，避免同一推导无说明地更换叫法．术语速查见 [术语表](../glossary/glossary.md)；数学记号仍以 [数学符号表](./symbol.md) 为准．本表约定正文主词，不将合理别名或跨语境用法视为知识错误．

| 语境        | 正文主词与说明                                 |
| --------- | --------------------------------------- |
| 抽象线性代数    | 向量、特征值、特征向量                             |
| 物理几何量与场   | 矢量、位置矢量（位矢）；曲线坐标的基向量等数学叫法可以保留           |
| 数学与场论微分映射 | 算子；Sturm–Liouville 问题用微分算子              |
| 量子态与观测量   | 算符、本征值、本征态；量子应用段不因出现在数学章节而改成另一套叫法       |
| 振动与相对论    | 固有频率、固有角频率；固有时、固有长度等相对论名称保留             |
| 热学状态与过程   | 物态方程（亦称状态方程）、等体过程（亦称等容过程）、定容热容、定压热容     |
| 热学量名      | 热容、比热容、物质的量、黏滞；一般气相物质用蒸气，蒸汽设备等固定行业名称可保留 |
| 物理与数学常量   | 普朗克常量、玻尔兹曼常量、气体常量；数学常数、积分常数、介电常数等按其含义保留 |
| 全称与简称     | 惯性参考系/惯性系、质心参考系/质心系等可以共存；质点系统正文优先称质点系   |

热学统一以 $A$ 表示系统对外做功，$A>0$ 表示能量以功的方式流出系统，以 $Q>0$ 表示吸热，第一定律为 $Q=\Delta U+A$．制冷机输入功的正值大小写为 $A_{\rm in}=-A>0$．对照其他资料的 $W_{\rm on}$ 等记号时必须明确给出换算，不能在正文中悄然换用另一套正负号．摩尔热容用 $C_{V,m}$、$C_{p,m}$ 等，总热容用 $C_V$、$C_p$，并明确 $C_V=\nu C_{V,m}$．

译名沿用 [项目方针](./what-pl-wiki-is-not.md#physics-learning-wiki-不是译名标准委员会) 的通行名原则．正文主名为费曼、海森堡、菲涅尔、范德瓦尔斯、史瓦西、约当；首次出现补英文，其他译名在术语表登记．英文缩写、软件标识、代码、引用原文及资源路径不机械中文化．玻恩/波恩等确实指错人的写法应纠正；有争议的译名不能仅因字形不同列为知识错误．

同句出现向量与矢量、算子与算符可能是在比较语境或解释别名，应核对所指对象，不能仅凭共现判错．符号表作为数学记号目录可以使用通用的「向量」；正文描述物理量时按本节语境区分．

## 概念引用与页面先修

首次有教学意义地回顾已学概念时，可用 `[名称](concept:registered-id)`；当前主线必需的新概念仍要就地解释．示例中的 ID 是语法占位，实际编辑须使用已注册 ID．在 frontmatter 的 `prerequisites` 中声明直接依赖，构建生成「本页需要」．正文只补充需要会到哪一步，不再手写同一份先修名单，也不要求全部引用都列为先修．

注册表 `data/concepts.yml` 的 ID、纯文本摘要、目标与生成术语条目，以及页面目标/题集的契约检查，见 [概念注册与关联检查](./editorial-review.md#概念注册与关联检查)．正文注册表与题库分类表各自核对，不假定存在自动映射．

## 页面状态与元数据规范

<span id="页面三态生命周期"></span>

### 状态与索引分开维护

| 状态          | 当前使用含义与行为                                  |
| ----------- | ------------------------------------------ |
| `planned`   | 规划或大纲，不能包装为已可自学；建设页须显式声明 `noindex, follow` |
| `draft`     | 起草完善中，不能据此声称已经完成审阅                         |
| `review`    | 审校中，当前页面模板显示此提示，不表示正式审核通过                  |
| `stable`    | 现有完成态约定；模板支持此值，但标签本身不能证明科学正确或独立审核          |
| `community` | 社区投稿；当前模板提示未经团队审核                          |

当前模板对缺省状态按 `stable` 处理，不应据此推断历史页面已经过审核．主分支的内容变更工作流会将检测到的 `stable` 页面改成 `review`；不能写成「改为 stable 并合并就会保持完成态」．本轮保留现有行为，状态调整须依据实际审阅，不能由 AI 自动晋级．

索引和 sitemap 依据最终 HTML 的 canonical 与 robots 指令，不由 `status` 自动决定．规划建设页应明确写：

```yaml
status: planned
meta:
  - name: robots
    content: noindex, follow
```

页面达到可公开阅读条件后，由维护者核实是否移除 `noindex`，补充准确的 `description`，构建后检查最终 HTML 与 sitemap．不手工伪造 sitemap 的日期、优先级或更新频率．本站位于 GitHub Pages 子路径，`docs/robots.txt` 不能代替主机根目录的 robots 文件．

### 内部工程资料

planning、spec 和 ADR 放在已有 `exclude_docs` 覆盖的工程目录中，不作为公开知识页维护．

## 发布前自检

确认本页任务与标题、描述一致，关键解释与条件在主线可读，符号和模型没有无提示切换．检查图文、概念链接、锚点与实际可用的练习；新增主线时同步核对上级导读与相关路线．不靠空泛预告、重复总结或关键词堆砌增加篇幅．

修改说明应交代保留内容、修改范围、科学核验及未验证项．可执行的分流流程、呈现检查和最小记录见 [编辑审校](./editorial-review.md)．
