## 学习路线总览

## 这份路线图适合谁

-   第一次系统学习大学物理的本科生．
-   过去学过零散知识、但没有完整框架的自学者．
-   已经开始刷题或做竞赛、但想回到主线补基础的读者．

## 使用原则

1.  先完成一遍主线，再进入竞赛、专题和高强度刷题．
2.  支撑模块与学科主线并行推进，不要等「数学全学完了」才开始学物理．
3.  每进入一个新主题，都先弄清楚它在解决什么问题，而不是只背定义和公式．
4.  当你读不动某一页时，优先回到先修页或导学页，而不是继续硬啃．

## 五个阶段

| 阶段 | 目标                                  | 重点模块                         |
| -- | ----------------------------------- | ---------------------------- |
| 预备 | 建立符号、量纲、函数、导数、积分、向量和基本测量观念．         | 数学工具、实验物理、术语表                |
| 入门 | 完成第一遍大学物理主线，建立力、能量、热、场、波和现代物理的基本图景． | 经典力学、热学与统计物理、电磁学、光学、近代物理     |
| 核心 | 把不同模块中的共通结构串起来，例如守恒律、场的观点、平衡与稳定性．   | 经典力学、电磁学、热学与统计物理、光学          |
| 进阶 | 学习更抽象或更深层的理论组织方式．                   | 分析力学、统计物理、麦克斯韦方程组、量子力学基础、相对论 |
| 专题 | 通过竞赛、题库、实验建模和计算工具做第二遍强化．            | 竞赛相关、实验物理、计算物理与工具、参考资料       |

## 推荐主线顺序

1.  先从 [数学工具](../math/index.md) 中补齐微积分、矢量分析和线性代数里最常用的部分．
2.  从 [经典力学](../mechanics/index.md) 开始，建立建模、受力分析、守恒律和微分方程的基本能力．
3.  接着学习 [热学与统计物理](../thermodynamics/index.md)，训练你用宏观量描述复杂系统，并理解热过程的方向性．
4.  然后进入 [电磁学](../electromagnetism/index.md)，从电场、磁场、电路与电磁波理解相互作用的场论描述．
5.  再学习 [光学](../optics/index.md)，把几何图景、波动图景和实验现象连接起来．
6.  在完成以上主线后，再进入 [近代物理](../modern/index.md)，理解相对论和量子理论为什么必须出现．
7.  [实验物理](../experiment/index.md) 与 [计算物理与工具](../tools/index.md) 建议全程并行，用来帮助你把理论和真实问题连接起来．

## 竞赛与专题如何放置

[竞赛相关](../contest/index.md) 是专题支线，而不是总站主入口．更合理的顺序是：

1.  先完成大学物理主线的第一遍．
2.  再进入竞赛方法、题型和专题强化．
3.  最后用题库、实验、计算和资料整理做第二遍回看．

如果你现在主要在准备竞赛，也建议定期回到主线模块确认自己没有把「会做题」误当成「理解了知识结构」．

## 三种常见使用方式

### 本科跟课

-   先阅读对应学科的导学页．
-   再按课程进度进入正文页．
-   每周回到路线图检查自己跳过了哪些先修内容．

### 自学补课

-   不要同时开太多模块．
-   先完成力学和热学这两段主线，再扩展到电磁、光学和现代物理．
-   读不懂时优先补数学、实验和术语，而不是继续往后翻．

### 竞赛或专题强化

-   先确认自己是否已经完成主线第一遍．
-   再进入 [竞赛学习路线](../contest/roadmap.md)．
-   把竞赛当成强化与迁移，而不是当成整个知识体系的替代品．
