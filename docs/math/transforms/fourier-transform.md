## 傅里叶变换

## 物理问题引入：当周期无限大时，如何分析非周期单次脉冲？

傅里叶级数成功解决了周期性振动和谐波分解问题．然而，物理实验中更普遍的是 **非周期瞬态过程**：

-   飞秒激光器发射出的单次超快光脉冲；
-   地震产生的单次孤立地震波；
-   一个在真空中自由传播的局域量子波包．

对于这类定义在 $(-\infty, \infty)$ 且非周期的信号，分立的基频与整数倍泛音不再适用．
如果我们令周期 $L \to \infty$，相邻分立频率之间的间隔 $\Delta k = \frac{\pi}{L} \to 0$，无穷密集的离散谱线就会自然汇聚成 **连续的能量频谱**——这就是 **傅里叶变换 (Fourier Transform)**．

***

## 1. 傅里叶变换的数学定义

### 1.1 空间 - 波数对标形式（物理对称约定）

设函数 $f(x) \in L^1(\mathbb{R})$，其一维连续傅里叶正变换 $\hat{f}(k) = \mathcal{F}[f(x)]$ 与逆变换 $\mathcal{F}^{-1}[\hat{f}(k)]$ 定义为：

$$
\hat{f}(k) = \dfrac{1}{\sqrt{2\pi}} \int_{-\infty}^{\infty} f(x) e^{-i k x} \mathrm{d}x
$$

$$
f(x) = \dfrac{1}{\sqrt{2\pi}} \int_{-\infty}^{\infty} \hat{f}(k) e^{i k x} \mathrm{d}k
$$

### 1.2 时间 - 角频率对标形式

在处理随时间 $t$ 演化的物理信号时，通常约定核为 $e^{-i\omega t}$：

$$
F(\omega) = \int_{-\infty}^{\infty} f(t) e^{i\omega t} \mathrm{d}t, \quad f(t) = \dfrac{1}{2\pi} \int_{-\infty}^{\infty} F(\omega) e^{-i\omega t} \mathrm{d}\omega
$$

正变换将「时域/空域波形」翻译为「频谱/波矢振幅谱」；逆变换则将连续正弦波基底 $e^{i k x}$ 按谱密度加权合成原始波形．

***

## 2. 傅里叶变换的核心运算性质

傅里叶变换之所以成为理论物理求解微分方程的首选工具，是因为它具有把 **微积分运算转化为纯代数乘除** 的魔力：

| 性质           | 空间域 $f(x)$                              | 频域 $\hat{f}(k)$          | 物理意义                                                              |                                     |                         |                 |                     |
| :----------- | :-------------------------------------- | :----------------------- | :---------------------------------------------------------------- | ----------------------------------- | ----------------------- | --------------- | ------------------- |
| **空间导数代数化**  | $\dfrac{\mathrm{d}^n f}{\mathrm{d}x^n}$ | $(i k)^n \hat{f}(k)$     | **将微分算子 $\frac{\mathrm{d}}{\mathrm{d}x}$ 转化为代数乘子 $ik$**，波动方程降为代数式 |                                     |                         |                 |                     |
| **平移相移定理**   | $f(x - x_0)$                            | $e^{-i k x_0}\hat{f}(k)$ | 空间平移只产生线性相位延迟，不改变功率谱                                              |                                     |                         |                 |                     |
| **尺度伸缩**     | $f(a x) \quad (a \neq 0)$               | \$\dfrac{1}{             | a                                                                 | }\hat{f}\left(\dfrac{k}{a}\right)\$ | 空间压缩对应频谱展宽（短脉冲必定携带极宽频带） |                 |                     |
| **普朗歇尔能量定理** | \$\int\_{-\infty}^{\infty}              | f(x)                     | ^2\mathrm{d}x\$                                                   | \$\int\_{-\infty}^{\infty}          | \hat{f}(k)              | ^2\mathrm{d}k\$ | 全时空波包总能量与频域全谱能量严格守恒 |

## 3. 卷积定理 (Convolution Theorem)

两个函数 $f(x)$ 与 $g(x)$ 的 **卷积 (Convolution)** 定义为：

$$
(f * g)(x) = \int_{-\infty}^{\infty} f(\tau) g(x - \tau) \mathrm{d}\tau
$$

### 定理陈述

两函数卷积的傅里叶变换，等于各自傅里叶变换的 **简单代数乘积**：

$$
\mathcal{F}[(f * g)(x)] = \sqrt{2\pi} \, \hat{f}(k) \hat{g}(k)
$$

反之，乘积的傅里叶变换对应频域的卷积．

**物理图景**：
在光学成像、电子滤波与介质响应中，输出信号 $y(t)$ 是输入信号 $x(t)$ 与系统脉冲响应函数 $h(t)$ 的时域卷积：$y = x * h$．
经过傅里叶变换后，复杂的积分卷积瞬间变成极简的乘积：$Y(\omega) = X(\omega) H(\omega)$！只需代数相除 $H(\omega) = Y(\omega)/X(\omega)$，即可瞬间测定系统的 **传递函数**．

## 4. 高斯波包与海森堡不确定性原理

考察物理中最优雅的高斯波包：

$$
f(x) = \exp\left(-\dfrac{x^2}{2\sigma_x^2}\right)
$$

对其进行傅里叶变换（利用高斯积分配方法）：

$$
\hat{f}(k) = \dfrac{1}{\sqrt{2\pi}}\int_{-\infty}^{\infty} e^{-x^2/(2\sigma_x^2)} e^{-ikx}\mathrm{d}x = \sigma_x \exp\left(-\dfrac{k^2 \sigma_x^2}{2}\right)
$$

高斯函数的傅里叶变换依然是高斯函数！
若定义频域宽度为 $\sigma_k = \dfrac{1}{\sigma_x}$，则两者的均方差之积严格为常数：

$$
\sigma_x \cdot \sigma_k = 1
$$

对于任意非高斯波包，泛函分析证明均方差乘积必定满足不确定性不等式：

$$
\Delta x \cdot \Delta k \ge \dfrac{1}{2}
$$

???+ tip "海森堡不确定性原理的纯数学本源"
    在量子力学中，粒子的动量由德布罗意关系给出：$p = \hbar k$．
    将 $\Delta k = \Delta p / \hbar$ 代入上式，立刻直接推导出：
    
    $$
    \Delta x \cdot \Delta p \ge \dfrac{\hbar}{2}
    $$
    
    这深刻表明：**测不准原理并非仪器测量精度的实验局限，而是波动力学与傅里叶变换的纯内在数学对称性！**

## 5. 跨模块物理应用

### 5.1 夫琅禾费单缝衍射

在物理光学中，夫琅禾费远场衍射光场的复振幅分布，数学上精确等于孔径透射率函数的 **二维空间傅里叶变换**．单缝矩形透射函数的傅里叶变换直接给出了衍射条纹的 $\text{sinc}(k)$ 分布．

### 5.2 量子力学坐标表象与动量表象

量子体系的波函数 $\psi(x)$ 与动量波函数 $\phi(p)$ 互为傅里叶变换对：

$$
\phi(p) = \dfrac{1}{\sqrt{2\pi\hbar}} \int_{-\infty}^{\infty} \psi(x) \exp\left(-i\dfrac{px}{\hbar}\right) \mathrm{d}x
$$

位置算符 $\hat{x}$ 与动量算符 $\hat{p} = -i\hbar \frac{\mathrm{d}}{\mathrm{d}x}$ 的对易子 $[\hat{x}, \hat{p}] = i\hbar$ 正是傅里叶求导性质的算子化写照．
