# 求留数专项：单极点极限法

先约分判定是否为一阶极点，再消去一次因子并取极限。 本套共 5 题，按基础计算、条件辨析和方法核对逐步练习。

## 1. 约去单极点因子 {#q-000055}

用极限法求 $f(z)=(z+2)/[(z-1)(z+3)]$ 在 $z=1$ 的留数。

??? note "提示"
    先计算 $(z-1)f(z)$。

??? note "参考答案与解析"
    **结果**：$3/4$。

    $z=1$ 处只有一次分母因子，分子非零。消去它后，$(z-1)f(z)=(z+2)/(z+3)$ 在 $1$ 解析，取值为 $3/4$。

题库编号：`q-000055`。

## 2. 分母另一因子的符号 {#q-000056}

用极限法求 $f(z)=e^z/[z(z-2)]$ 在 $z=0$ 的留数。

??? note "提示"
    消去 $z$，再代入原点。

??? note "参考答案与解析"
    **结果**：$-1/2$。

    原点为一阶极点。$zf(z)=e^z/(z-2)$ 在原点解析，极限为 $e^0/(0-2)=-1/2$。负号来自另一个分母因子，不能把 $z-2$ 写成 $2-z$。

题库编号：`q-000056`。

## 3. 看似单极点的可去点 {#q-000057}

判断 $f(z)=\sin z/(z-\pi)$ 在 $z=\pi$ 的奇点类型并求留数；若可去，求延拓值。

??? note "提示"
    检查分子在 $\pi$ 处是否也为零。

??? note "参考答案与解析"
    **结果**：可去奇点；留数为 $0$；延拓值为 $-1$。

    令 $w=z-\pi$，$\sin(\pi+w)=-\sin w=-w+O(w^3)$，故 $f=-1+O(w^2)$。分子的一阶零点抵消分母，主部为零，留数为零，延拓值为 $-1$。$\lim(z-\pi)f(z)=0$ 并不证明这里是单极点。

题库编号：`q-000057`。

## 4. 约分改变奇点分类 {#q-000058}

求 $f(z)=(z-1)/(z^2-1)$ 在 $z=1,-1$ 的留数，并分别判定奇点类型。

??? note "提示"
    $z^2-1=(z-1)(z+1)$。

??? note "参考答案与解析"
    **结果**：$z=1$ 可去，留数 $0$；$z=-1$ 为一阶极点，留数 $1$。

    在原定义域上约分得 $f(z)=1/(z+1)$。在 $z=1$ 可补定义 $f(1)=1/2$，留数为零；在 $z=-1$，$\lim_{z\to-1}(z+1)f(z)=1$，因此是一阶极点，留数为 $1$。

题库编号：`q-000058`。

## 5. 傅里叶核的单极点 {#q-000059}

设 $a>0$，用极限法求 $f(z)=e^{iz}/(z^2+a^2)$ 在 $z=ia$ 的留数。

??? note "提示"
    分母分解为两个不同的一次因子。

??? note "参考答案与解析"
    **结果**：$e^{-a}/(2ia)$。

    $z^2+a^2=(z-ia)(z+ia)$，且 $ia\ne-ia$。消去 $z-ia$ 后得到 $e^{iz}/(z+ia)$，在 $ia$ 的值为 $e^{-a}/(2ia)$。指数因子中的 $i^2=-1$ 给出衰减符号。

题库编号：`q-000059`。
