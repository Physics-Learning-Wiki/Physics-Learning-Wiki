# 留数习题集

这组练习配合[求留数：方法选择与计算](../residue-methods.md)及[留数定理与实积分计算](../residue-calculus.md)，依据讲义 3.5–3.7 节与方法选择表组织。先用专项练熟计算，再在综合题中自己决定方法。

| 题集 | 题量 | 训练重点 |
| --- | --- | --- |
| [洛朗展开法](laurent.md) | 5 | 寻找本性奇点展开中的 $a_{-1}$；乘积中要匹配所有指数和为 $-1$ 的项。 |
| [单极点极限法](simple-pole.md) | 5 | 先约分判定是否为一阶极点，再消去一次因子并取极限。 |
| [商式法 $P/Q^{\prime}$](quotient.md) | 5 | 验证分母为一阶零点，使用 $P(z_0)/Q^{\prime}(z_0)$。 |
| [高阶极点公式](higher-pole.md) | 5 | 消去实际极点，求 $m-1$ 阶导数，并除以 $(m-1)!$。 |
| [泰勒系数法](taylor.md) | 5 | 把解析因子展开到所需次数，取与分母配合产生 $-1$ 次幂的系数。 |
| [无穷远点与留数总和](infinity.md) | 5 | 读出无穷远展开的 $1/z$ 系数，区分有限留数之和与无穷远点留数。 |
| [综合题集](comprehensive.md) | 44 | 自主选方法、围道方向、参数积分、微分方程系数、余切核求和 |

综合卷复用全部 30 道专项题，另含 10 道新题及 4 道旧题，因此本次新增独立题目为 **40 道**，不是 74 道。各题都有参考结果和关键推导；专项另有折叠提示，综合卷隐藏方法分组和提示。

## 怎样使用

1. 先复习奇点分类和六种方法的条件。
2. 独立写出推导，避免只填一个结果。
3. 展开解析，检查阶数、阶乘、负号和系数配对。
4. 综合卷按混合顺序作答；自由作答题以「尚未掌握、部分掌握、基本掌握」自评。
