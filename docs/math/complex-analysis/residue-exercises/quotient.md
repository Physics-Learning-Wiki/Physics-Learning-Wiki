# 求留数专项：商式法 $P/Q^{\prime}$

验证分母为一阶零点，使用 $P(z_0)/Q^{\prime}(z_0)$。 本套共 5 题，按基础计算、条件辨析和方法核对逐步练习。

先独立完成奇点类型、所选公式和计算结果，再展开提示或解析。自由作答题按推导过程自评，不要求答案文字完全一致。

## 1. 四个极点的统一公式 {#q-000060}

求 $f(z)=2z/(z^4+1)$ 的全部有限极点及各点留数。

??? note "提示"
    先写单位根，再计算 $P/Q^{\prime}$。

??? note "参考答案与解析"
    **结果**：$z_k=e^{i(\pi/4+k\pi/2)}$，$k=0,1,2,3$；每点为一阶极点，留数为 $1/(2z_k^2)$。

    分母零点满足 $z^4=-1$，得到所列四根，均非零。$Q^{\prime}(z_k)=4z_k^3\ne0$ 且 $P(z_k)=2z_k\ne0$，所以各点为一阶极点。商式法给出 $2z_k/(4z_k^3)=1/(2z_k^2)$。按 $k$ 顺序，留数为 $-i/2,i/2,-i/2,i/2$，和为零。

题库编号：`q-000060`。

## 2. 复数导数的符号 {#q-000061}

用商式法求 $f(z)=e^z/(z^4-1)$ 在 $z=i$ 的留数。

??? note "提示"
    先算 $i^3$，最后再化简 $1/i$。

??? note "参考答案与解析"
    **结果**：$ie^i/4$。

    $Q(i)=i^4-1=0$，$Q^{\prime}(i)=4i^3=-4i\ne0$。因 $e^i\ne0$，该点为一阶极点。留数为 $e^i/(-4i)=ie^i/4$，这里 $1/i=-i$。

题库编号：`q-000061`。

## 3. 无限多个孤立单极点 {#q-000062}

求 $f(z)=1/(e^z-1)$ 在每个 $z_n=2\pi in$（$n\in\mathbb Z$）处的留数。

??? note "提示"
    分母的导数还是 $e^z$。

??? note "参考答案与解析"
    **结果**：各点留数均为 $1$。

    $e^{z_n}=1$，且分母导数 $e^{z_n}=1\ne0$，故每点为一阶极点。分子是常数 $1$，商式法得到留数 $1$。奇点虽然无限多个，但在有限平面中没有聚点，每个点都可以单独求留数。

题库编号：`q-000062`。

## 4. 余切的整数极点 {#q-000063}

求 $f(z)=\pi\cot(\pi z)$ 在任意整数 $z=n$ 处的留数。

??? note "提示"
    把余切写成余弦与正弦的商。

??? note "参考答案与解析"
    **结果**：$1$。

    写成 $P/Q=\pi\cos(\pi z)/\sin(\pi z)$。在 $n$ 处，$P(n)=\pi(-1)^n$，$Q^{\prime}(n)=\pi\cos(\pi n)=\pi(-1)^n\ne0$。二者相除为 $1$；分母求导时必须保留链式法则的 $\pi$。

题库编号：`q-000063`。

## 5. 先列全零点 {#q-000064}

求 $f(z)=(z^2+1)/(z^3-z)$ 的全部有限极点及对应留数。

??? note "提示"
    用 $Q^{\prime}(z)=3z^2-1$，逐点代入。

??? note "参考答案与解析"
    **结果**：$-1,0,1$ 都是一阶极点，留数依次为 $1,-1,1$。

    $Q=z(z-1)(z+1)$，三个零点互异，分子在这三点均非零。$Q^{\prime}=3z^2-1$，故在 $\pm1$ 处留数为 $2/2=1$，原点处为 $1/(-1)=-1$。其和为 $1$，与无穷远展开的 $1/z$ 系数一致。

题库编号：`q-000064`。
