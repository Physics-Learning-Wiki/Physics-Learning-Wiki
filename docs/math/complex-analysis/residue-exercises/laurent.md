# 求留数专项：洛朗展开法

寻找本性奇点展开中的 $a_{-1}$；乘积中要匹配所有指数和为 $-1$ 的项。 本套共 5 题，按基础计算、条件辨析和方法核对逐步练习。

## 1. 指数的基本留数 {#q-000050}

判断 $f(z)=e^{1/z}$ 在 $z=0$ 的奇点类型，并求 $\operatorname{Res}(f,0)$。

??? note "提示"
    在指数级数中寻找 $z^{-1}$。

??? note "参考答案与解析"
    **结果**：本性奇点；留数为 $1$。

    $e^{1/z}=\sum_{n=0}^{\infty}z^{-n}/n!$ 在任意 $0<|z|<r$ 内成立。主部有无穷多项，所以原点为本性奇点；$n=1$ 对应 $z^{-1}$，其系数为 $1$。

题库编号：`q-000050`。

## 2. 幂次移动 {#q-000051}

求 $f(z)=z^2e^{2/z}$ 在 $z=0$ 的留数，并说明原点的奇点类型。

??? note "提示"
    写出 $2-n=-1$。

??? note "参考答案与解析"
    **结果**：$\operatorname{Res}(f,0)=4/3$；本性奇点。

    展开 $z^2e^{2/z}=\sum_{n=0}^{\infty}(2^n/n!)z^{2-n}$。令 $2-n=-1$ 得 $n=3$，故留数为 $2^3/3!=4/3$。乘以 $z^2$ 后主部仍有无穷多项，原点仍为本性奇点。

题库编号：`q-000051`。

## 3. 正弦本性奇点 {#q-000052}

求 $\sin(1/z)$ 在原点的留数。能否使用有限阶极点的求导公式？

??? note "提示"
    将正弦的幂级数中的自变量换成 $1/z$。

??? note "参考答案与解析"
    **结果**：留数为 $1$；不能使用有限阶极点公式。

    $\sin(1/z)=\sum_{n=0}^{\infty}(-1)^n z^{-(2n+1)}/(2n+1)!$。$n=0$ 给出 $1/z$，故留数为 $1$。主部有无穷多项，不存在有限的极点阶数 $m$，所以高阶极点公式不适用。

题库编号：`q-000052`。

## 4. 无穷多项的系数配对 {#q-000053}

在 $0<|z|<1$ 内展开 $f(z)=e^{1/z}/(1-z)$，求原点的留数。说明为什么只取 $e^{1/z}$ 的 $1/z$ 项会出错。

??? note "提示"
    匹配指数 $k-n=-1$。

??? note "参考答案与解析"
    **结果**：$\operatorname{Res}(f,0)=e-1$。

    在该圆环内，$e^{1/z}=\sum_{n\ge0}z^{-n}/n!$，$(1-z)^{-1}=\sum_{k\ge0}z^k$。两个级数在紧子集上一致绝对收敛，可以相乘。$k-n=-1$ 即 $n=k+1$，因此留数为 $\sum_{k\ge0}1/(k+1)!=e-1$。各个 $k$ 都有贡献，不能仅保留 $n=1$。

题库编号：`q-000053`。

## 5. 余弦与一次负幂 {#q-000054}

判断 $f(z)=\cos(1/z)/z$ 在原点的奇点类型并求留数。

??? note "提示"
    除以 $z$ 后，每一项的指数减一。

??? note "参考答案与解析"
    **结果**：本性奇点；留数为 $1$。

    $\cos(1/z)/z=\sum_{n\ge0}(-1)^n z^{-(2n+1)}/(2n)!$。主部无穷，原点为本性奇点。$n=0$ 的系数为 $1$，就是留数。不要把 $\cos(1/z)$ 本身的零留数直接用于乘积。

题库编号：`q-000054`。
