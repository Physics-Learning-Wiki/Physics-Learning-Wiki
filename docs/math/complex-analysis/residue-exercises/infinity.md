# 求留数专项：无穷远点与留数总和

读出无穷远展开的 $1/z$ 系数，区分有限留数之和与无穷远点留数。 本套共 5 题，按基础计算、条件辨析和方法核对逐步练习。

先独立完成奇点类型、所选公式和计算结果，再展开提示或解析。自由作答题按推导过程自评，不要求答案文字完全一致。

## 1. 有限留数和与负号 {#q-000075}

求 $f(z)=(3z+1)/(z^2-1)$ 的无穷远点留数和全部有限留数之和，并用局部计算核对。

??? note "提示"
    先提取 $1/z$ 系数，再区分两个问题的符号。

??? note "参考答案与解析"
    **结果**：无穷远点留数 $-3$；有限留数之和 $3$；$1,-1$ 处留数为 $2,1$。

    无穷远展开为 $f(z)=3/z+1/z^2+O(z^{-3})$。无穷远点留数是 $1/z$ 系数的负值，所以为 $-3$，有限和为 $3$。局部商式法给出 $(3+1)/2=2$ 和 $(-3+1)/(-2)=1$，和为 $3$。

题库编号：`q-000075`。

## 2. 快速确定四点留数和 {#q-000076}

不逐个计算极点，求 $f(z)=1/(z^4+1)$ 的全部有限留数之和及无穷远点留数。

??? note "提示"
    用 $1/z$ 作小量展开。

??? note "参考答案与解析"
    **结果**：两者均为 $0$。

    $f(z)=z^{-4}(1+z^{-4})^{-1}=z^{-4}-z^{-8}+\cdots$，没有 $1/z$ 项，所以无穷远点留数为零，有限留数之和也为零。这里有限极点依然存在，留数和为零不能推出每个留数为零。

题库编号：`q-000076`。

## 3. 三次单位根 {#q-000077}

求 $f(z)=z^2/(z^3-1)$ 的无穷远点留数与有限留数之和，再求各有限极点的留数。

??? note "提示"
    比较无穷远展开与商式法。

??? note "参考答案与解析"
    **结果**：无穷远点留数 $-1$；有限和 $1$；每个三次单位根处留数为 $1/3$。

    $f(z)=z^{-1}(1-z^{-3})^{-1}=z^{-1}+z^{-4}+\cdots$，故无穷远点留数为 $-1$，有限和为 $1$。三个极点 $\zeta^3=1$ 互异，$Q^{\prime}(\zeta)=3\zeta^2$，留数 $\zeta^2/(3\zeta^2)=1/3$。单靠总和不能断定三者相等，需要这一步局部验证。

题库编号：`q-000077`。

## 4. 多项式部分不贡献留数 {#q-000078}

求 $f(z)=z^3/(z^2+1)$ 的无穷远点留数与全部有限留数之和。能否直接用 $-\lim_{z\to\infty}zf(z)$？

??? note "提示"
    先进行多项式除法。

??? note "参考答案与解析"
    **结果**：无穷远点留数 $1$；有限和 $-1$；不能使用该极限捷径。

    先长除得 $f(z)=z-z/(z^2+1)=z-z^{-1}+O(z^{-3})$。$1/z$ 系数为 $-1$，故无穷远点留数为 $1$，有限和为 $-1$。$zf(z)$ 含 $z^2$ 项而发散，捷径不适用。局部计算在 $\pm i$ 处各得 $z^3/(2z)=z^2/2=-1/2$。

题库编号：`q-000078`。

## 5. 总和反求另一点 {#q-000079}

求 $f(z)=(z^2+1)/[z^2(z-2)]$ 的无穷远点留数，并利用 $z=2$ 处留数反求原点留数。

??? note "提示"
    列出全部有限奇点，确保没有漏项。

??? note "参考答案与解析"
    **结果**：无穷远点留数 $-1$；$z=2$ 留数 $5/4$；原点留数 $-1/4$。

    $f(z)=z^{-1}(1+z^{-2})(1-2/z)^{-1}=z^{-1}+O(z^{-2})$，有限和为 $1$，无穷远点留数为 $-1$。$z=2$ 为单极点，留数为 $(2^2+1)/2^2=5/4$。仅有两个有限极点，故原点留数 $1-5/4=-1/4$；也可对 $(z^2+1)/(z-2)$ 在原点求一次导数核对。

题库编号：`q-000079`。
