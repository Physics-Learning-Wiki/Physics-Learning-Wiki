# 求留数专项：泰勒系数法

把解析因子展开到所需次数，取与分母配合产生 $-1$ 次幂的系数。 本套共 5 题，按基础计算、条件辨析和方法核对逐步练习。

## 1. 只展开到三次 {#q-000070}

用泰勒系数法求 $e^z/z^4$ 在原点的留数。

??? note "提示"
    取 $e^z$ 的三次项系数。

??? note "参考答案与解析"
    **结果**：$1/6$。

    $e^z=1+z+z^2/2+z^3/6+O(z^4)$，除以 $z^4$ 后，只有三次项变成 $z^{-1}$，所以留数为 $1/6$。原点是四阶极点。

题库编号：`q-000070`。

## 2. 实际阶数与形式分母 {#q-000071}

用泰勒系数法求 $\sin z/z^4$ 在原点的留数，并确定实际极点阶数。

??? note "提示"
    正弦的最低非零项是一阶项。

??? note "参考答案与解析"
    **结果**：留数 $-1/6$；三阶极点。

    $\sin z=z-z^3/6+O(z^5)$，所以 $\sin z/z^4=z^{-3}-(1/6)z^{-1}+O(z)$。最高负幂为 $z^{-3}$，实际阶数是三阶；留数为 $-1/6$。用 $g=\sin z,m=4$ 取三次系数也正确，但不能据此把实际阶数称作四阶。

题库编号：`q-000071`。

## 3. 分子相消后再取系数 {#q-000072}

求 $(e^z-1-z)/z^5$ 在原点的留数与实际极点阶数。

??? note "提示"
    需要分子的四次项，而阶数由二次项决定。

??? note "参考答案与解析"
    **结果**：留数 $1/24$；三阶极点。

    $e^z-1-z=z^2/2+z^3/6+z^4/24+O(z^5)$。除以 $z^5$ 后主部为 $1/(2z^3)+1/(6z^2)+1/(24z)$，故留数 $1/24$，极点阶数三阶。不能把分子减去的常数和线性项再计入。

题库编号：`q-000072`。

## 4. 解析因子的卷积 {#q-000073}

求 $f(z)=e^z/[z^3(1+z)]$ 在原点的留数，只展开解析因子到必要次数。

??? note "提示"
    二次系数由 $0+2$、$1+1$、$2+0$ 三种组合给出。

??? note "参考答案与解析"
    **结果**：$1/2$。

    在 $|z|<1$ 内，$e^z=1+z+z^2/2+O(z^3)$，$(1+z)^{-1}=1-z+z^2+O(z^3)$。乘积的二次系数为 $1-1+1/2=1/2$。除以 $z^3$ 后它就是留数；只看 $e^z$ 的二次项虽碰巧同值，却不能省略另外两个贡献。

题库编号：`q-000073`。

## 5. 只需要一次系数 {#q-000074}

求 $f(z)=\cos z/[z^2(1-z)]$ 在原点的留数。

??? note "提示"
    分母为 $z^2$，只需解析因子的一次项。

??? note "参考答案与解析"
    **结果**：$1$。

    $\cos z=1+O(z^2)$，$(1-z)^{-1}=1+z+O(z^2)$，故解析因子的乘积为 $1+z+O(z^2)$。除以 $z^2$，得到 $z^{-2}+z^{-1}+O(1)$，留数为 $1$。无需展开到二次以上。

题库编号：`q-000074`。
