## CMC 竞赛与非数学类初赛定位

全国大学生数学竞赛（Chinese Mathematics Competitions, CMC）由中国数学会主办，是面向全国本科生的高水平学科竞赛．竞赛分为数学专业类与非数学专业类两个赛道，每年秋季学期进行初赛（预赛），次年春季学期举行决赛．

对于物理学、应用物理及其他理工程类本科生而言，CMC 非数学类初赛是检验并深化高等数学（微积分、常微分方程、向量代数与多元微积分）工具掌握程度的重要实战平台．不同于常规课程的套公式考核，竞赛试题更加注重极限分析的深刻理解、积分不等式放缩技巧、中值定理的综合构造以及几何与物理背景下的多元微积分综合应用．

为支持同学系统化练习与能力诊断，本站推出 CMC 线上小测与自评系统．读者可按原卷题序全真练习，交卷后通过评分标准自主评估步骤分，并依据薄弱知识点直接返回相关数学工具章节进行针对性回学．

## 线上小测流程与考后自评机制

CMC 初赛试卷兼具客观填空题与需要详细写出推导论证的解答题．本站题集采用**整卷提交 · 考后自评**（`self_assessment_timing: after_submit`）运行流程：

| 阶段 | 考生界面与保存行为 |
| --- | --- |
| **作答中** | 按照原卷真实题序推进，支持跳题浏览、标记存疑与中断后恢复续答．自由作答题填写证明推导与解题核心步骤，系统按有效文字计入答题进度．全卷提示、详细解析与参考解答在交卷前全部严格隐藏，允许保留空题交卷． |
| **已交卷 · 待自评** | 提交后系统立即自动锁定作答文本并保存记录，防止后续被动修改．随后开放标准参考解答与分步评分细则（Rubric）．读者针对已作答的解答题对照步骤评分，空题自动标为未作答．若中途退出，刷新后自动恢复至待自评状态． |
| **练习完成** | 当所有作答解答题均完成等级自评后，生成最终答卷报告并计入「练习积分」．系统明确区分客观题自动判分与主观题自评得分；仅客观题判错会计入错题本，方便后续循环巩固． |

## 考点分布与数学工具回学导引

CMC 非数学类初赛试卷的核心考查范围涵盖大学物理学习所需的微积分主线工具．建议在模拟练习前后对照以下路线复习基础定理与推导方法：

1. **极限与连续**：包括未定式定值、泰勒展开阶数匹配、重要极限变形、夹逼准则与数列极限单调有界定理．
   - 回学导引：[极限与分析基础](../math/calculus/limit.md)
2. **一元微分学与中值定理**：包括高阶导数求法、罗尔定理、拉格朗日中值定理与柯西中值定理的辅助函数构造、导数应用与不等式证明．
   - 回学导引：[导数与微分核心概念](../math/calculus/derivative.md)
3. **一元积分学与不等式**：包括变上限积分函数求导、分部积分与换元法技巧、定积分不等式（如柯西–施瓦茨积分不等式）与反常积分收敛性判别．
   - 回学导引：[积分方法与微积分基本定理](../math/calculus/integral.md)
4. **常微分方程**：包括一阶微分方程标准解法、可降阶高阶方程、二阶常系数线性非齐次方程特解求解与简易物理建模．
   - 回学导引：[物理常微分方程入门](../math/calculus/ode.md)
5. **多元函数微积分与场论**：包括偏导数与全微分、多元极值与拉格朗日乘数法、重积分对称性简化与极坐标/柱坐标/球坐标变换、第一类与第二类线面积分以及格林公式、高斯公式与斯托克斯公式．
   - 回学导引：[矢量积分定理与应用](../math/vector-analysis/integral-theorems.md)
