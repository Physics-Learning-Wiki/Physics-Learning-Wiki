## 竞赛相关简介

本模块用于整理物理竞赛、学术竞赛与专题训练资源，但它不再作为 Physics Learning Wiki 的总站主线．对于大多数本科生和自学者，更合理的顺序是先完成 [学习路线总览](../intro/roadmap.md) 中的主线学习，再把竞赛当作第二遍强化．

## 这部分适合谁

-   已完成大学物理主线第一遍，想通过题目和专题训练加深理解的读者．
-   正在准备中学物理竞赛、IPhO、APhO、CPhO 等赛事的读者．
-   参加 CUPT 等大学生学术竞赛，需要资料、实验、建模和展示能力支持的读者．

## 竞赛模块在总站中的位置

竞赛训练可以帮助你看到高质量题目、典型方法和反直觉现象，但它不能替代系统学习．本站对竞赛模块的定位是：

1.  用题目和专题回头检验主线理解．
2.  为特定赛事提供资料与方法整理．
3.  帮助读者在完成主线后进行第二遍强化．

如果你现在还处于第一遍系统学习阶段，建议优先阅读 [经典力学](../mechanics/index.md)、[热学与统计物理](../thermodynamics/index.md) 和 [电磁学](../electromagnetism/index.md) 等主线模块．

## 这部分怎么用

1.  先阅读 [竞赛学习路线](./roadmap.md)，判断自己是在做基础补强、题型整理还是赛事准备．
2.  再结合 [学习资源](./resources.md)、[考试策略](./strategy.md) 和 [常见错误](./common-mistakes.md) 安排训练．
3.  如果你准备的是 CUPT，还应同时并行阅读 [实验物理](../experiment/index.md) 与 [计算物理与工具](../tools/index.md)．

## 对贡献者的建议

竞赛页面不应只堆题单和经验帖．更有价值的内容包括：

-   为什么这类题目能检验某个核心概念．
-   题型与大学物理主线之间的连接．
-   常见误区、错误直觉和复盘方法．
-   训练节奏、资料选择和能力结构的说明．

如果你只是整理零散经验，也欢迎通过 [GitHub](../intro/htc.md) 或邮箱 <submit@folderrewind.top> 投稿，由编辑组协助整理成正式页面．
