## 近代物理章节编写说明

本页是近代物理模块的章节级补充规范．它关注的核心问题是：如何把相对论、量子、原子、核和固体这些内容写成「经典理论为何失效、现代观念如何建立」的连续过程，而不是只堆一串反直觉结论．

## 本模块的写作目标

近代物理主线整体应帮助读者完成以下四件事：

1.  看见经典理论失效的具体原因，而不是把现代物理当成凭空降临的新规则．
2.  把实验事实、理论假设和数学结论区分开来．
3.  逐步建立对相对论时空观和量子观念的接受能力．
4.  为后续的原子、核、粒子和凝聚态课程建立概念入口．

## 目标读者与默认前提

默认读者是第一次系统学习近代物理的本科生或自学者．写作时请默认他们：

-   学过基础力学、电磁学和光学，但尚未完全接受其适用范围有限．
-   容易把现代物理的结论当成「违反常识的结论集」．
-   容易在还没理解实验背景前，就被数学形式和术语压住．

首次引入新理论时说明依据和问题来源；面向具备先修的读者，方法页可以直接从公设或数学对象开始．

## 推荐叙事顺序

近代物理模块建议遵循下面的展开顺序：

1.  先说明经典理论在高速、强引力或微观尺度上的失效．
2.  再引入相对论和量子论的核心观念．
3.  接着把这些新观念用于原子、核、粒子和固体等具体系统．
4.  最后再进入更抽象的数学与统一性讨论．

## 可选的问题入口

新理论引入可以比较旧模型的边界，实验或方法页也可直接开始其任务．例如：

-   狭义相对论页：为什么经典绝对时空观会与电磁理论发生冲突．
-   波粒二象性页：为什么光和电子都不能只用单一经典图像解释．
-   薛定谔方程页：为什么需要一种新的状态演化语言．
-   算符与测量页：为什么量子理论中的可观测量不能照搬经典变量概念．
-   原子物理页：为什么经典轨道模型无法稳定解释原子结构．

## 按页面任务组织

本模块沿用 [内容编写指引](../intro/writing.md) 的质量底线，不另设固定栏目与出现顺序．上述问题可用于概念引入或方法比较；速查、导读和工具页可以直接开始当前任务，无需逐页重讲动机．

## 例题应该如何安排

按任务选择观念变化、实验解释或方法应用，不要求每题对比经典理论．可采用以下类型：

-   经典理论失效的反例题．
-   关键实验结果解释题．
-   思想实验与概念辨析题．
-   基本量级、极限和近似判断题．
-   新旧理论对照题．

## 近代物理例题的推荐写法

例题区分实验事实、公设与数学后果，说明采用的尺度和近似．新旧理论对照只用于确实需要比较的任务；方法页可以直接计算，不必重演一次经典理论危机．通用的解题解释与结果检查见 [内容编写指引](../intro/writing.md#推导例题与练习)，本页不重复一套解题模板．

## 写近代物理时最容易犯的错误

-   不说明实验背景，直接抛出结论或公设．
-   用过度口号化的语言代替精确定义，例如把「量子很神秘」当解释．
-   还没建立观念就急着上最一般的数学形式．
-   用经典图像做类比，却不提醒类比何时失效．
-   把不确定性、测量、叠加等概念写成流行表述而不是物理问题．

## 页面之间的衔接建议

-   从经典物理到狭义相对论，应强调「高速情形下的冲突」．
-   从经典光学到波粒二象性，应强调「实验事实逼迫我们改写图像」．
-   从波粒二象性到薛定谔方程与算符，应强调「新图像需要新数学语言」．
-   从量子基础到原子、核与固体，应强调「抽象观念如何落到具体系统」．

## 提交前检查清单

在提交近代物理页面前，请至少确认：

1.  页面任务和所用模型是否明确；引入新理论时是否说明必要依据．
2.  是否区分了实验事实、理论假设和数学后果．
3.  例题是否解释模型与方法；涉及观念变化时是否说明其依据．
4.  是否提示了经典类比的边界和常见误解．
5.  是否给出了自然的前置页面和后续页面跳转．
