## 综合推导题

### 综合题 1：非均匀极化与电荷守恒

无限长半径 R 的圆柱，给定极化 P=αs e_s，圆柱外 P=0，无自由电荷也无附加外场．求束缚体面密度、单位长度总束缚电荷、D 和内外 E，并检验边界跃变．

题库编号：`q-000556`．

??? note "分步解答与自评"
    1. $\rho_b=-s^{-1}\mathrm{d}(sP_s)/\mathrm{d}s=-2\alpha$；侧面 $\sigma_b=\alpha R$．单位长度两项为 $-2\pi\alpha R^2$ 与 $+2\pi\alpha R^2$，和为零．
    2. 圆柱对称、轴上正则且无自由电荷，D 的高斯关系给 $\boldsymbol D=0$，所以内部 $\boldsymbol E=-\alpha s\boldsymbol e_s/\varepsilon_0$，外部为零．
    3. 外减内法向场为 $\alpha R/\varepsilon_0=\sigma_b/\varepsilon_0$，符合总电荷边界关系．
    4. 本题给定 P，不额外要求普通线性无外场介质自发具有同一 P．评分含柱坐标散度、面法向、总量和跃变检验．

### 综合题 2：介质球的自洽场

半径 R、常数正介电系数 ε 的线性球处于真空均匀外场 E0 e_z．用内外调和势及无自由界面电荷条件求场和总偶极矩，再用退极化关系独立验证．

题库编号：`q-000557`．

??? note "分步解答与自评"
    1. 设内势 $-Ar\cos\theta$，外势 $-E_0r\cos\theta+B\cos\theta/r^2$．势连续得 $A=E_0-B/R^3$，D 法向连续得 $\varepsilon A=\varepsilon_0(E_0+2B/R^3)$．
    2. 解得 $A=3\varepsilon_0E_0/(\varepsilon+2\varepsilon_0)$，$B=(\varepsilon-\varepsilon_0)E_0R^3/(\varepsilon+2\varepsilon_0)$，总偶极矩为 $4\pi\varepsilon_0B\boldsymbol e_z$．
    3. 另用 $\boldsymbol E=\boldsymbol E_0-\boldsymbol P/(3\varepsilon_0)$ 与 $\boldsymbol P=(\varepsilon-\varepsilon_0)\boldsymbol E$ 得同一内场．
    4. ε=ε₀ 时无扰动，ε/ε₀ 趋大时内场趋零．评分含全边界、总场响应及至少两个极限检验．

### 综合题 3：介质插入的能量与力

平板长 L、宽 b、间距 d，刚性线性介质板填满间距，已插入长度 x．忽略边缘对电容的高阶修正，求 C(x)；分别求固定 U 和固定 Q 时的插入力，解释局部边缘场与总能量法的关系．

题库编号：`q-000558`．

??? note "分步解答与自评"
    1. 按并排面积分区，有 $C(x)=\varepsilon_0b[L+(\varepsilon_r-1)x]/d$，所以 $C'=\varepsilon_0b(\varepsilon_r-1)/d$．
    2. 固定 U：$F_x=U^2C'/2$；固定 Q：$F_x=Q^2C'/(2C^2)$．普通 εr>1 时均指向插入方向，但沿过程的力值不同．
    3. 固定 U 的电源输入 $U\mathrm{d}Q=U^2\mathrm{d}C$，一半增加储能，一半输出机械功；固定 Q 则机械功来自储能减少．
    4. 局部力的空间分布涉及边缘非均匀场；总电容的领先构型变化仍可给领先合力．评分须限制刚性、准静态、线性可逆与无损模型，不能声称局部边缘场不存在．

## 自测答案与反馈

??? note "作答后展开核对"
    1. **C**．既计大小也计方向，单位为 C/m²．
    A：那是体电荷密度，单位为 C/m³． B：电流与这里的静态偶极密度不同． C：既计大小也计方向，单位为 C/m²．
    
    2. **B**．体密度由散度给出，表面由法向分量给出．
    A：常矢量的散度为零． B：体密度由散度给出，表面由法向分量给出． C：忽略了边界处极化的变化．
    
    3. **A**．球面法向随极角变化，P 与法向点积给密度．
    A：球面法向随极角变化，P 与法向点积给密度． B：只有法向与 P 一致的位置才等于 P． C：体密度零不代表表面密度零．
    
    4. **C**．球几何给退极化因子 1/3．
    A：这是法向极化大板内部的几何结果． B：退极化场与极化方向相反． C：球几何给退极化因子 1/3．
    
    5. **B**．该整理使 D 的散度等于自由电荷密度．
    A：遗漏真空电场贡献． B：该整理使 D 的散度等于自由电荷密度． C：符号与束缚密度 −∇·P 的移项不符．
    
    6. **A**．边界、旋度与本构仍参与确定辅助场．
    A：边界、旋度与本构仍参与确定辅助场． B：零净通量不代表局部场为零． C：束缚电荷参与真实总场．
    
    7. **C**．响应须与极化产生的附加场自洽．
    A：忽略了极化对内部总场的反馈． B：宏观参数与微观局域场不可直接混为一谈． C：响应须与极化产生的附加场自洽．
    
    8. **B**．分别来自小柱高斯关系与静电小回路．
    A：法向 E 可因束缚面电荷跃变． B：分别来自小柱高斯关系与静电小回路． C：把两类边界条件交换了．
    
    9. **A**．无自由界面电荷使 Dn 相同，电压按层积分．
    A：无自由界面电荷使 Dn 相同，电压按层积分． B：两层厚度与介电系数不同时电压不同． C：介电系数不同会使 E=D/ε 不同．
    
    10. **C**．球面条件与退极化因子共同给出该响应．
    A：不能把大板几何的因子用于球． B：有限正介电系数的一般绝缘球不等于导体． C：球面条件与退极化因子共同给出该响应．
    
    11. **B**．非线性需沿充电路径积分，滞回还涉及耗散．
    A：源类型不能代替本构与可逆性条件． B：非线性需沿充电路径积分，滞回还涉及耗散． C：忽略了色散、损耗与非线性．
    
    12. **A**．电源输入是场能增量的两倍，忽略损耗时另一半为机械功．
    A：电源输入是场能增量的两倍，忽略损耗时另一半为机械功． B：这是把固定电荷与固定电压过程混用． C：不能只对场能取负导数而漏掉电源．
