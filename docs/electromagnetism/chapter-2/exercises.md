## 综合推导题

### 综合题 1：保守性、零点与分段势

先由点电荷场证明静电环路定理，再求均匀带电实心长圆柱的电势，圆柱半径 $R$、体密度 $\rho$，取 $\varphi(R)=0$．讨论能否改取无穷远零势，并验证势的导数．

题库编号：`q-000547`．

??? note "分步解答与自评"
    1. 点场有 $\boldsymbol E\cdot\mathrm{d}\boldsymbol l=kQ\,\mathrm{d}r/r^2=-\mathrm{d}(kQ/r)$，端点相同则积分零．固定多源由线性叠加推广，路径须避开奇点．
    2. 圆柱内场为 $\rho s/(2\varepsilon_0)$，外场为 $\rho R^2/(2\varepsilon_0s)$．分别从 R 积分：内势 $\rho(R^2-s^2)/(4\varepsilon_0)$，外势 $-\rho R^2\ln(s/R)/(2\varepsilon_0)$．
    3. 势在表面连续，负导数恢复两区场．无限圆柱外场积分到无穷远对数发散，不能要求有限的无穷远零势．
    4. 评分核对：证明、叠加条件、分段积分常数、导数与远处条件分别自检．

### 综合题 2：偶极子的完整场与误差

两点电荷 $\pm q$ 位于 $z=\pm a$．从精确电势展开得到偶极远场，再求球坐标和坐标无关的场．用正轴精确解估计 $z=10a$ 处领先项的误差．

题库编号：`q-000548`．

??? note "分步解答与自评"
    1. $\varphi=kq(1/|\boldsymbol r-a\boldsymbol e_z|-1/|\boldsymbol r+a\boldsymbol e_z|)$，$p=2qa$，远处得 $\varphi\simeq kp\cos\theta/r^2$．
    2. 负梯度给 $E_r=2kp\cos\theta/r^3$、$E_\theta=kp\sin\theta/r^3$，合成 $\boldsymbol E=k[3(\boldsymbol p\cdot\boldsymbol n)\boldsymbol n-\boldsymbol p]/r^3$．
    3. 正轴精确式为 $2kpz^{-3}(1-a^2/z^2)^{-2}$．相对领先项的首个修正约 $2a^2/z^2$，在 $10a$ 处约百分之二．
    4. 评分核对：说明远场条件、角向尺度因子、特殊方向与误差的适用含义．

### 综合题 3：方框四极子与原点变换

在 $(a,a,0)$、$(-a,-a,0)$ 放 $+q$，另两角放 $-q$．证明单极与偶极为零，计算无迹四极矩并写领先电势．讨论平移原点后领先阶是否改变．

题库编号：`q-000549`．

??? note "分步解答与自评"
    1. 四角电荷和为零，位置加权电荷和也为零，所以 $Q=0$、$\boldsymbol p=0$．
    2. 按 $\mathcal Q_{ij}=\sum q(3x_ix_j-r^2\delta_{ij})$ 逐项求和，对角与含 z 项抵消，$\mathcal Q_{xy}=\mathcal Q_{yx}=12qa^2$．
    3. 电势为 $12kqa^2xy/r^5=6kqa^2\sin^2\theta\sin2\phi/r^3$ 的领先项；场按四次反比衰减．
    4. 当总电荷与偶极都为零，平移不改变四极矩；完整物理势也不变．评分需包括矩约定、角因子及原点条件，不能只给衰减阶次．

## 十二题概念与方法自测

每题的正确项与反馈收于末尾，先记录答案再展开核对．多选题须完整选对全部正确项；判断题明确写出正确或错误．

### 自测 1

在任何静电场中，电场线都绝不可能形成闭合曲线．这是因为静电场是有心力平方反比场导出的保守场，若存在闭合电场线，沿该闭合线移动电荷一周静电力将做非零净功，从而违背静电场环路定理 $\oint_L \boldsymbol{E} \cdot \mathrm{d}\boldsymbol{l} = 0$．

题库编号：`q-000013`．


### 自测 2

半径为 $R$ 的无限长金属薄圆柱面上均匀带电，单位轴向长度电荷量为 $\lambda$（$\lambda > 0$）．若选对称轴线（$r = 0$ 处）为电势参考零点（$V(0) = 0$）．关于空间各区域离轴线距离为 $r$ 处的电势分布，下列表达式正确的是：

题库编号：`q-000022`．

- A．圆柱面内部（$r \le R$）$V_{\text{内}}(r) = 0$；圆柱面外部（$r \ge R$）$V_{\text{外}}(r) = \dfrac{\lambda}{2\pi\varepsilon_0}\ln\dfrac{R}{r}$
- B．圆柱面内部（$r \le R$）$V_{\text{内}}(r) = \dfrac{\lambda r}{2\pi\varepsilon_0 R}$；圆柱面外部（$r \ge R$）$V_{\text{外}}(r) = \dfrac{\lambda}{2\pi\varepsilon_0}\ln\dfrac{r}{R}$
- C．圆柱面内部（$r \le R$）$V_{\text{内}}(r) = 0$；圆柱面外部（$r \ge R$）$V_{\text{外}}(r) = \dfrac{\lambda}{2\pi\varepsilon_0}\left(\dfrac{1}{R} - \dfrac{1}{r}\right)$
- D．全空间各区域电势均处处相等且恒等于零

### 自测 3

在静电场中，电场线与等势面（Equipotential Surface）在几何拓扑与微分分析中紧密对应．下列关于等势面几何性质及其与电场强度的微分关系，哪些说法是正确的？

题库编号：`q-000015`．

- A．静电场中的电场线在空间各点恒处处与该点所在的等势面保持正交（垂直）
- B．电场强度矢量 $\boldsymbol{E}$ 恒指向空间电势降落最快的方向，其微分数学关系满足 $\boldsymbol{E} = -\nabla U$
- C．当规定相邻两等势面之间的电势差恒定相等（$\Delta U = \text{常数}$）时，等势面越密集的地方场强越大，等势面越稀疏的地方场强越小
- D．沿同一等势面移动任意电荷时，电场力所做的功恒严格等于零

### 自测 4

正电荷 $q$ 均匀分布在半径为 $R$ 的细绝缘圆环上．取圆环中心为坐标原点，通过环心且垂直于环面的对称轴为 $x$ 轴．选无穷远处为电势参考零点．关于轴线上距环心为 $x$ 处的电势 $V(x)$ 分布，下列说法正确的是：

题库编号：`q-000016`．

- A．轴线电势为 $V(x) = \dfrac{q}{4\pi\varepsilon_0 \sqrt{x^2 + R^2}}$，并在环心处取得全局极大值 $V(0) = \dfrac{q}{4\pi\varepsilon_0 R}$
- B．轴线电势为 $V(x) = \dfrac{q x}{4\pi\varepsilon_0 (x^2 + R^2)^{3/2}}$，在环心处电势为零
- C．轴线电势为 $V(x) = \dfrac{q}{4\pi\varepsilon_0 (x + R)}$，电势随离开环心的距离呈反比例线性衰减
- D．轴线电势在环心处发散为无穷大，在远处退化为偶极子电势（按 $1/x^2$ 衰减）

### 自测 5

真空中有一半径为 $R$ 的均匀带电薄绝缘圆盘，其电荷面密度为 $\sigma$（$\sigma > 0$），总电荷量为 $Q = \sigma \pi R^2$．取圆盘中心为原点，垂直于盘面的对称轴为 $x$ 轴．选无穷远处为电势参考零点．关于轴线上距盘心为 $x$（$x > 0$）处的电势与场强分析，下列哪些结论是正确的？

题库编号：`q-000017`．

- A．轴线上各点的电势分布为 $V(x) = \dfrac{\sigma}{2\varepsilon_0}\left(\sqrt{x^2 + R^2} - x\right)$
- B．圆盘中心点（$x = 0$）处的电势有限且达到最大值，大小为 $V(0) = \dfrac{\sigma R}{2\varepsilon_0}$
- C．当处于极远距离（$x \gg R$）时，对根号进行一阶泰勒展开，电势渐近退化为点电荷电势 $V(x) \approx \dfrac{Q}{4\pi\varepsilon_0 x}$
- D．对轴线电势函数求负偏导 $E_x = -\dfrac{\mathrm{d}V}{\mathrm{d}x}$，可以直接求出轴线场强 $E_x = \dfrac{\sigma}{2\varepsilon_0}\left(1 - \dfrac{x}{\sqrt{x^2 + R^2}}\right)$

### 自测 6

真空中有一半径为 $R$、总带电量为 $Q$ 的均匀带电薄球壳．选无穷远处为电势参考零点．关于该球壳在空间各点所激发的电势分布，下列说法正确的是：

题库编号：`q-000018`．

- A．球壳外部（$r \ge R$）电势为 $V(r) = \dfrac{Q}{4\pi\varepsilon_0 r}$；球壳内部（$r < R$）电势处处恒定，等于表面电势 $V(r) = \dfrac{Q}{4\pi\varepsilon_0 R}$，整个球壳内部空间是一个等势体
- B．球壳外部（$r \ge R$）电势为 $V(r) = \dfrac{Q}{4\pi\varepsilon_0 r}$；由于球壳内部场强为零，故球壳内部（$r < R$）各点的电势也处处为零
- C．球壳内部（$r < R$）电势随距球心的距离 $r$ 呈线性递增，在球表面达到峰值后向外按 $1/r$ 衰减
- D．跨越球壳表面时，电势函数发生不连续跳变，跳变量大小为 $\Delta V = \dfrac{\sigma}{\varepsilon_0}$

### 自测 7

总电荷量为 $Q$ 的正电荷均匀分布在半径为 $R$ 的实心球体内（体电荷密度 $\rho = \dfrac{Q}{\dfrac{4}{3}\pi R^3}$）．选无穷远处为电势参考零点．关于球体内部离球心距离为 $r$（$r \le R$）处的电势分布 $V(r)$ 及其与表面电势 $V(R)$ 的定量关系，下列结论正确的是：

题库编号：`q-000020`．

- A．球内电势呈二次抛物线分布 $V(r) = \dfrac{Q(3R^2 - r^2)}{8\pi\varepsilon_0 R^3}$，球心处电势达到全局最高值，且恰好等于表面电势的 $1.5$ 倍（$V(0) = 1.5\,V(R)$）
- B．球内电势呈线性递减分布 $V(r) = \dfrac{Q(2R - r)}{8\pi\varepsilon_0 R^2}$，球心处电势等于表面电势的 $2$ 倍
- C．球内电势处处恒定为 $V(r) = \dfrac{Q}{4\pi\varepsilon_0 R}$，球内空间各点电势与表面电势严格相同
- D．球内电势为二次抛物线 $V(r) = \dfrac{Q r^2}{4\pi\varepsilon_0 R^3}$，在球心处电势降落为零

### 自测 8

真空中有一根「无限长」均匀带电细直线，电荷线密度为 $\lambda$（$\lambda > 0$）．若选取距该直线垂直距离为 $r_B$ 处的点 $B$ 作为电势参考零点（$V(r_B) = 0$）．则距直线垂直距离为 $r$ 处的点 $P$ 的电势 $V(r)$ 为：

题库编号：`q-000021`．

- A．$V(r) = \dfrac{\lambda}{2\pi\varepsilon_0}\ln\dfrac{r_B}{r}$
- B．$V(r) = \dfrac{\lambda}{2\pi\varepsilon_0}\ln\dfrac{r}{r_B}$
- C．$V(r) = \dfrac{\lambda}{4\pi\varepsilon_0}\left(\dfrac{1}{r} - \dfrac{1}{r_B}\right)$
- D．$V(r) = \dfrac{\lambda}{2\pi\varepsilon_0}\dfrac{r_B - r}{r r_B}$

## 自测答案与反馈

??? note "作答后展开核对"
    1. **正确**．若一条普通非零静电场线闭合，沿它的场切向积分同号，无法满足零环流；因此不能形成这种闭合场线．此论证使用静电条件．
    
    2. **A**．薄圆柱壳内零场，轴线零势使整个内区及表面势都为零．壳外为 $-\lambda\ln(r/R)/(2\pi\varepsilon_0)$，负导数恢复径向场，势在表面连续．
    
    3. **A、B、C、D**．在电场非零、等势面光滑处，负梯度与势面正交．比较疏密还要保证相邻势差相等；同一势面上场力功为零．零场点不具有唯一的场线切向，不能把正交图像机械外推．
    
    4. **A**．圆环轴线上各电荷到场点等距，势为 $kq/\sqrt{R^2+x^2}$．中心势有限且最大，远处才近似点电荷势；电场还要对位置求负导数．
    
    5. **A、B、C、D**．把圆盘按同心环积分，正轴势为 $\sigma(\sqrt{x^2+R^2}-x)/(2\varepsilon_0)$．中心连续有限，远场恢复有限总电荷的点势；轴向负导数求场还用到了横向对称性．
    
    6. **A**．壳内零场意味着常势而非零势．以无穷远零势时，壳外为 $kQ/r$，通过表面连续性确定内部常数 $kQ/R$．
    
    7. **A**．从表面势 $kQ/R$ 向内积分线性内场，得到 $kQ(3-r^2/R^2)/(2R)$．内部是二次函数，中心有限且导数为零，表面与外部解连续相接．
    
    8. **A**．积分无限线的场得到 $\varphi(r)=\lambda\ln(r_B/r)/(2\pi\varepsilon_0)$．对数自变量无量纲，$r=r_B$ 时为零；正线电荷的势沿径向减小．
    
    9. **A**．相同局部源项并不消除齐次解．
    A：相同局部源项并不消除齐次解． B：数学定理仍成立，缺少的是物理边界数据． C：匀强静电场具有线性电势．
    
    10. **C**．沿 x 位移势能升高，沿 y 位移下降，不能三维稳定．
    A：只检查 x 方向会漏掉 y 方向的不稳定． B：原点梯度为零，平衡与稳定要分开． C：沿 x 位移势能升高，沿 y 位移下降，不能三维稳定．
    
    11. **B**．有限偶极保留更高阶项，特殊方向需分别检查误差．
    A：偶极领先项恰常用于总电荷为零的体系． B：有限偶极保留更高阶项，特殊方向需分别检查误差． C：靠近电荷时有限几何不能省略．
    
    12. **A**．单极、偶极均为零，四极势按三次反比衰减．
    A：单极、偶极均为零，四极势按三次反比衰减． B：这是偶极势的衰减阶次． C：四极电场按四次反比衰减，势比它少一次．
