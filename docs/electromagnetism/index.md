## 从电荷间的力走向空间中的场

电磁学研究电荷、电流与电磁场的相互作用．这条学习主线先解决静态问题：已知电荷怎样求场，未知分布怎样由边界确定，能量怎样随构型改变，材料又怎样响应外场．这些问题逐步建立后续理解电流、磁场、感应与电磁波所需的语言．

默认你学过力、功和基础微积分．不要求在起点掌握完整矢量分析；梯度、散度、旋度与积分定理会随物理需要进入正文．五章中唯一性证明、球面镜像与电四极子均为必读，核心推导不藏在默认折叠内容中．

## 五章之间的关系

第一章由源求场；第二章把功、势和局域方程连起来；第三章用导体和边界确定未知源分布；第四章通过能量理解储电与受力；第五章联立材料响应与场方程．球、平行板与偶极等模型会重复出现，但每次承担新的学习任务．

全程统一电势 $arphi$、电势差 $U_{AB}=arphi_A-arphi_B$ 与静电能 $W$．静电环路定理与标量电势的全局描述有明确条件，后续时变场中需要重新检查这些条件．
