## 综合推导题

### 综合题 1：混合边界唯一性

真空区域中源密度给定，一部分导体电势给定，其余导体净电荷给定，外边界条件相同．完整证明电场唯一，并解释所有边界只给净电荷时势零点的自由度．

题库编号：`q-000550`．

??? note "分步解答与自评"
    1. 两解作差 $w=\varphi_1-\varphi_2$，有 $\nabla^2w=0$．
    2. 对乘积散度 $\nabla\cdot(w\nabla w)$ 积分，得到 $\int|\nabla w|^2=\oint w\partial_nw$．指定电势的导体上 w 为零；指定净电荷的导体上 w 为常数且法向导数积分为零．
    3. 外边界或相同远处条件使剩余边界项消失，于是非负积分为零，梯度差为零．连通区域内 w 是共同常数．
    4. 固定势基准则常数为零；未固定基准时场仍唯一．评分须检查法向、边界逐项消失和外边界，不得把各导体电势都设为相等．

### 综合题 2：接地球与孤立球的构造

点电荷 $q$ 距半径 $R$ 的球心 $a>R$．推导接地球像的大小和位置，求受力；再将球改为给定净电荷 $Q_0$ 的孤立球，构造新解并给球势．

题库编号：`q-000551`．

??? note "分步解答与自评"
    1. 球面距离满足 $d_2=(R/a)d_1$ 时可逐点消势，比较余弦系数得像位置 $b=R^2/a$、像电荷 $q'=-qR/a$．
    2. 验证球面零势、无穷远衰减及区域内源正确．受力 $F_z=kqq'/(a-b)^2=-kq^2Ra/(a^2-R^2)^2$．
    3. 孤立球加中心像 $q_c=Q_0-q'$，球面仍等势，总像电荷为 $Q_0$，球势为 $kq_c/R$．力还须加 $kqq_c/a^2$．
    4. 评分核对：像放在区域外、边界逐点验证、净电荷约束与两个受力贡献．

### 综合题 3：屏蔽与操作顺序

孤立中性导体壳内放固定点电荷 $q>0$，壳外无其他源．比较接地前后金属净电荷和外部场；随后先断开接地再取走 q，求最终电荷与空腔场．讨论 q 偏心是否影响这些总量结论．

题库编号：`q-000552`．

??? note "分步解答与自评"
    1. 初始金属净电荷零，内面总电荷 −q，外面 +q；外部一般非零．若外形为球，外部等效球心点电荷 q．
    2. 接地后外边界零势、无外源，外场零，外面无电荷，金属净电荷 −q．
    3. 先断地保持 −q，再取走内部 q；空腔无源、内壁等势，内部零场，净电荷 −q 移到外表面．
    4. 偏心改变内面局部分布与腔内场，不改变上述净电荷约束．评分应分别说明材料、空腔、外部和操作时的电荷通路．

## 自测答案与反馈

??? note "作答后展开核对"
    1. **C**．自由电荷已调整到不再被宏观场驱动的状态．
    A：空腔不是金属材料，内部源可以产生场． B：表面电荷与外源通常产生外部场． C：自由电荷已调整到不再被宏观场驱动的状态．
    
    2. **B**．零净电荷分别约束各表面的积分，不直接规定电势．
    A：仅金属材料内部场为零． B：零净电荷分别约束各表面的积分，不直接规定电势． C：把积分电荷条件误当成共同电势条件．
    
    3. **A**．中板势为 $V=\sigma ab/[\varepsilon_0(a+b)]$，左面密度为 $\varepsilon_0V/a$．
    A：中板势为 $V=\sigma ab/[\varepsilon_0(a+b)]$，左面密度为 $\varepsilon_0V/a$． B：只有两间距相等时才平均分配． C：把右侧分配误用于左侧；较窄间隙对应较大电容．
    
    4. **C**．内壁等势且内部调和，最大值原理给常势．
    A：导体感应电荷会改变边界，不能忽略屏蔽． B：孤立壳也可使无源封闭腔零场，势常数可改变． C：内壁等势且内部调和，最大值原理给常势．
    
    5. **B**．金属内高斯面给内面 −q，金属净电荷守恒给外面．
    A：内部源必须被内表面感应电荷抵消其穿过金属的通量． B：金属内高斯面给内面 −q，金属净电荷守恒给外面． C：外面为零是无外源接地壳的结果，不是一般孤立壳．
    
    6. **A**．共同常数不改变电场，各导体相对电势不是随意的．
    A：共同常数不改变电场，各导体相对电势不是随意的． B：场唯一性已经排除这种改变． C：不同常数一般改变区域内电场并违反原净电荷数据．
    
    7. **C**．这些条件共同允许使用唯一性．
    A：一个点不能代表整个边界． B：总量不足以保证边界等势． C：这些条件共同允许使用唯一性．
    
    8. **B**．像电荷为 −q，与真实电荷距离为 2d．
    A：接地不等于无感应面电荷． B：像电荷为 −q，与真实电荷距离为 2d． C：把到平面的距离错当成到像的距离．
    
    9. **A**．由球面到两源的距离比例与所有角度上的零势条件得到．
    A：由球面到两源的距离比例与所有角度上的零势条件得到． B：该位置在球外，会给物理区域添加错误源． C：像在边界上会引入错误奇点．
    
    10. **C**．中心像只加球面常势，保留等势并满足净电荷条件．
    A：接地球的感应总电荷通常非零． B：这样失去球面等势条件． C：中心像只加球面常势，保留等势并满足净电荷条件．
    
    11. **B**．尖端增强不是无条件的局部反比律．
    A：理想静电分布主要由静电几何及约束决定． B：尖端增强不是无条件的局部反比律． C：把特殊相连远球近似推广成普遍定律．
    
    12. **A**．这一步与相容边界项消失配合，得到两解之差为常数．
    A：这一步与相容边界项消失配合，得到两解之差为常数． B：正负函数可积分抵消，非负性不可省． C：固定净电荷可以非零，证明比较的是相同数据的两解．
