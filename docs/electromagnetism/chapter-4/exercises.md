## 综合推导题

### 综合题 1：两种约束下的平行板运动

真空平行板面积 A、间距 d，比较固定 Q 与固定 U 时使 d 缓慢减小的过程．分别推导力，写出电源功、场能变化与机械功平衡，并用另一板的场核验．

题库编号：`q-000553`．

??? note "分步解答与自评"
    1. $C=\varepsilon_0A/d$．固定 Q 时 $W=Q^2d/(2\varepsilon_0A)$，力 $F_d=-Q^2/(2\varepsilon_0A)$．电源不做功，机械输出为场能减少．
    2. 固定 U 时 $\mathrm{d}W=U\mathrm{d}Q-F_d\mathrm{d}d$，$\mathrm{d}Q=U\mathrm{d}C$，因此 $F_d=U^2C'(d)/2=-\varepsilon_0AU^2/(2d^2)$．电源输入为场能增加的两倍．
    3. 同一瞬时场强下两式均为 $-\varepsilon_0E^2A/2$．用 $Q$ 乘另一板的场 $\sigma/(2\varepsilon_0)$ 验证，不能乘总场．
    4. 评分需包含坐标方向、固定量、电源项和独立受力检验．

### 综合题 2：球的两种能量算法

均匀实心球半径 R、总电荷 Q．分别用电荷—电势积分和全空间场积分求自能，再与同半径同电荷薄壳比较．说明点极限及负相互作用能与正场能的关系．

题库编号：`q-000554`．

??? note "分步解答与自评"
    1. 球内势为 $kQ(3-r^2/R^2)/(2R)$，$\rho=3Q/(4\pi R^3)$．代入 $W=\dfrac12\int_0^R\rho\varphi4\pi r^2\mathrm{d}r$ 得 $3kQ^2/(5R)$．
    2. 场积分分内外，内部为 $kQ^2/(10R)$、外部为 $kQ^2/(2R)$，相加一致．
    3. 薄壳只有外部贡献，能量较小．半径趋零的自能发散；点电荷负相互作用能是剔除自能后的交叉贡献，不与正的完整平方积分矛盾．
    4. 评分检查二分之一、体积权重、积分域、边界条件与模型限度．

### 综合题 3：永久与感生偶极

给定缓变静电外场 E，推导固定永久偶极的能量、力矩和净力．再设线性感生偶极 p=αE，从内部代价与耦合能极小化推导有效能与净力，解释二分之一因子．

题库编号：`q-000555`．

??? note "分步解答与自评"
    1. 两端势差展开给 $W=-\boldsymbol p\cdot\boldsymbol E$，角度求导给 $\boldsymbol\tau=\boldsymbol p\times\boldsymbol E$；固定 p 对位置求导得 $\boldsymbol F=\nabla(\boldsymbol p\cdot\boldsymbol E)$．
    2. 感生偶极总有效函数为 $p^2/(2\alpha)-\boldsymbol p\cdot\boldsymbol E$，极小化给 $\boldsymbol p=\alpha\boldsymbol E$，代回为 $-\alpha E^2/2$．
    3. 感生净力为 $\alpha\nabla E^2/2$．直接将 p 代进永久偶极能量漏掉建立响应的代价，会多一倍．
    4. 评分需写明给定外源、缓变、小粒子、线性与取向条件，不将有效能当作完整电源总能．

## 自测答案与反馈

??? note "作答后展开核对"
    1. **C**．$C=4\pi\varepsilon_0R$，与半径成正比．
    A：表面积增四倍不等于孤立球电容增四倍． B：电容依赖几何，不由电荷量单独决定． C：$C=4\pi\varepsilon_0R$，与半径成正比．
    
    2. **B**．节点两侧电荷和为零才给等量异号．
    A：预带净电荷的中节点会改变两电容的电荷关系． B：节点两侧电荷和为零才给等量异号． C：浮置不等于接地．
    
    3. **A**．金属内零场，电压只积累在总厚 d−t 的两真空间隙．
    A：金属内零场，电压只积累在总厚 d−t 的两真空间隙． B：忽略了金属内部不贡献电势降． C：t 是无场金属厚度，不是有效真空间距．
    
    4. **C**．二分之一用于把内部双重计数改为单次计数．
    A：给定外场没有相同的双重计数． B：会把相互作用能算两遍． C：二分之一用于把内部双重计数改为单次计数．
    
    5. **B**．分别为 $3kQ^2/(5R)$ 与 $kQ^2/(2R)$，实心球还含内部场能．
    A：相同外部场不代表全空间场能相同． B：分别为 $3kQ^2/(5R)$ 与 $kQ^2/(2R)$，实心球还含内部场能． C：两者外部贡献相同，球壳没有额外内部场能．
    
    6. **A**．有限区域或无限分布须重新检查，不能自动删除．
    A：有限区域或无限分布须重新检查，不能自动删除． B：分部积分总会产生边界项． C：即使没有导体，有限外边界也可能贡献．
    
    7. **C**．对实际感应力从无穷远积分，或使用二分之一 q 乘感应势．
    A：把像误当作独立固定真实源，能量多算一倍． B：吸引过程从无穷远靠近释放能量，势能为负． C：对实际感应力从无穷远积分，或使用二分之一 q 乘感应势．
    
    8. **B**．电源输入 $U^2\mathrm dC$，场能增加 $U^2\mathrm dC/2$．
    A：固定电压不代表电荷不流动． B：电源输入 $U^2\mathrm dC$，场能增加 $U^2\mathrm dC/2$． C：还要有一部分能量成为机械输出．
    
    9. **A**．总场含本板自场，受力只用另一板的场．
    A：总场含本板自场，受力只用另一板的场． B：不能把自场作为自身受力来源． C：相反，额外计入自场使结果过大．
    
    10. **C**．两端力反向等大，可构成力偶．
    A：均匀场没有强弱位置差． B：不平行时仍有 p×E 力矩． C：两端力反向等大，可构成力偶．
    
    11. **B**．须把建立偶极的内部代价与外场耦合共同极小化．
    A：中性粒子仍可有极化能与非均匀场合力． B：须把建立偶极的内部代价与外场耦合共同极小化． C：直接代入永久偶极公式漏掉响应建立能量．
    
    12. **A**．W=−2kp₁p₂/r³，径向力为负．
    A：W=−2kp₁p₂/r³，径向力为负． B：要分别检查正负电荷位置和角因子． C：总电荷零不消除偶极项．
