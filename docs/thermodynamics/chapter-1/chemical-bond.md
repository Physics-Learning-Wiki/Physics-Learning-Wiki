# 化学键

把物态只描述成“固体、液体、气体”还不够。真正决定物质为什么能形成稳定结构、为什么有的容易蒸发、有的熔点很高的，更深一层原因在于粒子之间的相互作用，也就是各种化学键与分子间作用。

## 学习目标

读完本页后，你应该能够：

- 理解化学键在热学第一章中的角色不是化学补课，而是解释物态差异的微观来源。
- 知道键强度、平衡距离和势能形状会怎样影响物质的宏观热学性质。
- 为后续比较固体、液体和相变行为建立更统一的图景。

## 为什么这里要插入化学键

如果只讲物态现象而不谈粒子间相互作用，读者很容易把“固体为什么稳”“液体为什么还能流动”理解成纯经验事实。化学键页的作用，就是在第一章内部搭起一座桥：把前面看到的宏观物态差别，和后面会逐渐展开的微观结构联系起来。

## 本页将重点处理什么

正文扩写时，这一页会重点讲：

1. 势能曲线与平衡距离的基本图像；
2. 离子键、共价键、金属键及分子间作用的简要区分；
3. 键强弱如何影响熔点、沸点、硬度和热稳定性；
4. 为什么液体和固体常常不能只靠“是否有键”来粗糙地区分。
