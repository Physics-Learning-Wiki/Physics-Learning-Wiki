## 热学与统计物理简介

热学与统计物理研究的是：当系统包含大量粒子时，我们如何用少数宏观量描述它，并解释热现象为什么会朝某个方向发生。

## 为什么要学这一章

- 帮助你区分温度、热量、内能、功、熵这些最容易混淆的概念。
- 帮助你理解“平衡态”“状态量”“过程量”这些宏观描述工具为什么必要。
- 帮助你把宏观热力学规律与微观粒子运动联系起来。
- 为后续的统计物理、材料、凝聚态、化学物理和工程热学打基础。

## 学习前建议掌握

- [经典力学](../mechanics/index.md) 中关于能量、做功和守恒关系的基本观念。
- [数学工具](../math/index.md) 中的函数、导数、积分和简单微分方程。
- 对概率与平均值有基本直觉会更顺利，但不是进入热学主线的前置门槛。

## 推荐阅读顺序

1. [热力学系统与状态](./system-state.md)：先学会“描述什么”。
2. [热力学定律](./laws.md)：再理解“系统如何演化”以及哪些过程不可能发生。
3. [气体动理论](./kinetic-theory.md)：把压强、温度等宏观量和微观运动联系起来。
4. [相变与临界现象](./phase-change.md)：理解状态变化、潜热和相界。
5. [统计物理基础](./statistical.md)：从微观态、概率和平均量解释宏观规律。

## 阅读这部分时要特别注意

1. 先分清状态量与过程量，不要把热量、功和内能混为一谈。
2. 先建立宏观热力学语言，再引入微观解释，不要一开始就把所有现象都塞进分子图景里。
3. 看到公式时，先问清楚研究对象是谁、过程条件是什么、符号约定是什么。
4. 第二定律相关内容要特别重视“为什么有方向性”，不要只记结论。

## 这部分希望你获得什么能力

学完热学主线后，你应该至少能够：

- 用系统、状态、过程这些语言描述一个热学问题。
- 判断热力学定律在一个问题中的作用。
- 解释温度、压强、热量、内能和熵之间的区别与联系。
- 读懂简单模型背后的物理前提，而不是只会套公式。
