# 贡献指南

本页是快速概览。详细说明请阅读 [如何参与](./intro/htc.md)、[内容编写指引](./intro/writing.md) 与 [格式手册](./intro/format.md)。

## 贡献入口

- **GitHub Pull Request**：适合熟悉 GitHub、希望直接改动页面内容的贡献者。
- **邮箱投稿**：适合不熟悉 GitHub，或暂时只有笔记、提纲、讲义、课堂整理的同学。投稿地址为 [submit@folderrewind.top](mailto:submit@folderrewind.top)。

## 适合投稿的内容

- 新章节或新页面。
- 纠错、补充定义、改写不清晰表述。
- 例题解析、学习路线建议、参考资料整理。
- 半成品笔记、提纲、讲义，由编辑组协助整理为正式页面。

## 基本要求

1. 内容应服务于本科入门/自学主线，而不是只面向已经学过的人。
2. 页面应说明它在解决什么问题、依赖什么先修、读完后应该去哪里。
3. 公式、符号、图片、引用和文件命名需要遵守现有格式规范。
4. 例题应帮助读者理解建模与判断，而不是只展示计算过程。

## 审核流程

1. 初步确认选题是否与现有结构重复或冲突。
2. 检查页面的结构、叙事和参考资料。
3. 根据需要补充格式、链接、作者信息和上下游页面连接。
4. 合并并继续迭代。

## 写作建议

- 先解释“为什么要学这个”，再进入定义和公式。
- 尽量给出例子、误区和前后章节连接。
- 如果你暂时写不成完整页面，也欢迎先投稿提纲和材料。
