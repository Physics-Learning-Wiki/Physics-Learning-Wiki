    傅里叶变换

    物理问题引入：当周期无限大时，如何分析非周期单次脉冲？

    傅里叶级数成功解决了周期性振动和谐波分解问题．然而，物理实验中更普遍的是 非周期瞬态过程：

    • 飞秒激光器发射出的单次超快光脉冲；
    • 地震产生的单次孤立地震波；
    • 一个在真空中自由传播的局域量子波包．

    对于这类定义在 ( −∞,∞)(−∞,∞)(-inf, inf) 且非周期的信号，分立的基频与整数倍泛音不再适用． 如果我们令周期 𝐿 →∞L→∞L -> inf，相邻分立频率之间的间隔 Δ𝑘 =𝜋𝐿 →0Δk=πL→0Delta k = pi/L -> 0，无穷密集的离散谱线就会自然汇聚成 连续的能量频谱——这就是 傅里叶变换（Fourier Transform）．

    1. 傅里叶变换的数学定义

    1.1 空间 - 波数对标形式（物理对称约定）

    设函数 𝑓(𝑥) ∈𝐿1(ℝ)f(x)∈L1(R)f(x) in L^1(R)，其一维连续傅里叶正变换 ˆ𝑓(𝑘) =F[𝑓(𝑥)]f^(k)=F[f(x)]f(k) = F[f(x)] 与逆变换 F−1[ˆ𝑓(𝑘)]F−1[f^(k)]F^-1[f(k)] 定义为：

    ˆ𝑓(𝑘)=1√2𝜋∫∞−∞𝑓(𝑥)𝑒−𝑖𝑘𝑥d𝑥f^(k)=12π∫−∞∞f(x)e−ikxdxf(k) = 12pi int_-inf^inf f(x) e^-i k x dx𝑓(𝑥)=1√2𝜋∫∞−∞ˆ𝑓(𝑘)𝑒𝑖𝑘𝑥d𝑘f(x)=12π∫−∞∞f^(k)eikxdkf(x) = 12pi int_-inf^inf f(k) e^i k x dk

    1.2 时间 - 角频率对标形式

    在处理随时间 𝑡tt 演化的物理信号时，通常约定核为 𝑒−𝑖𝜔𝑡e−iωte^-iomega t：

    𝐹(𝜔)=∫∞−∞𝑓(𝑡)𝑒𝑖𝜔𝑡d𝑡,𝑓(𝑡)=12𝜋∫∞−∞𝐹(𝜔)𝑒−𝑖𝜔𝑡d𝜔F(ω)=∫−∞∞f(t)eiωtdt,f(t)=12π∫−∞∞F(ω)e−iωtdωF(omega) = int_-inf^inf f(t) e^iomega t dt, quad f(t) = 12pi int_-inf^inf F(omega) e^-iomega t domega

    正变换将「时域/空域波形」翻译为「频谱/波矢振幅谱」；逆变换则将连续正弦波基底 𝑒𝑖𝑘𝑥eikxe^i k x 按谱密度加权合成原始波形．

    3. 卷积定理（Convolution Theorem）

    两个函数 𝑓(𝑥)f(x)f(x) 与 𝑔(𝑥)g(x)g(x) 的 卷积（Convolution） 定义为：

    (𝑓∗𝑔)(𝑥)=∫∞−∞𝑓(𝜏)𝑔(𝑥−𝜏)d𝜏(f∗g)(x)=∫−∞∞f(τ)g(x−τ)dτ(f * g)(x) = int_-inf^inf f(tau) g(x - tau) dtau

    定理陈述

    两函数卷积的傅里叶变换，等于各自傅里叶变换的 简单代数乘积：

    F[(𝑓∗𝑔)(𝑥)]=√2𝜋ˆ𝑓(𝑘)ˆ𝑔(𝑘)F[(f∗g)(x)]=2πf^(k)g^(k)F[(f * g)(x)] = 2pi , f(k) g(k)

    反之，乘积的傅里叶变换对应频域的卷积．

    物理图景： 在光学成像、电子滤波与介质响应中，输出信号 𝑦(𝑡)y(t)y(t) 是输入信号 𝑥(𝑡)x(t)x(t) 与系统脉冲响应函数 ℎ(𝑡)h(t)h(t) 的时域卷积：𝑦 =𝑥 ∗ℎy=x∗hy = x * h． 经过傅里叶变换后，复杂的积分卷积瞬间变成极简的乘积：𝑌(𝜔) =𝑋(𝜔)𝐻(𝜔)Y(ω)=X(ω)H(ω)Y(omega) = X(omega) H(omega)！只需代数相除 𝐻(𝜔) =𝑌(𝜔)/𝑋(𝜔)H(ω)=Y(ω)/X(ω)H(omega) = Y(omega)/X(omega)，即可瞬间测定系统的 传递函数．

    4. 高斯波包与海森堡（Heisenberg）不确定性原理

    考察物理中最优雅的高斯波包：

    𝑓(𝑥)=exp⁡(−𝑥22𝜎2𝑥)f(x)=exp⁡(−x22σx2)f(x) = expleft(-x^22sigma_x^2right)

    对其进行傅里叶变换（利用高斯积分配方法）：

    ˆ𝑓(𝑘)=1√2𝜋∫∞−∞𝑒−𝑥2/(2𝜎2𝑥)𝑒−𝑖𝑘𝑥d𝑥=𝜎𝑥exp⁡(−𝑘2𝜎2𝑥2)f^(k)=12π∫−∞∞e−x2/(2σx2)e−ikxdx=σxexp⁡(−k2σx22)f(k) = 12piint_-inf^inf e^-x^2/(2sigma_x^2) e^-ikxdx = sigma_x expleft(-k^2 sigma_x^22right)

    高斯函数的傅里叶变换依然是高斯函数！ 若定义频域宽度为 𝜎𝑘 =1𝜎𝑥σk=1σxsigma_k = 1sigma_x，则两者的均方差之积严格为常数：

    𝜎𝑥⋅𝜎𝑘=1σx⋅σk=1sigma_x * sigma_k = 1

    对于任意非高斯波包，泛函分析证明均方差乘积必定满足不确定性不等式：

    Δ𝑥⋅Δ𝑘≥12Δx⋅Δk≥12Delta x * Delta k >= 12
    海森堡不确定性原理的纯数学本源

    在量子力学中，粒子的动量由德布罗意关系给出：𝑝 =ℏ𝑘p=ℏkp = hbar k． 将 Δ𝑘 =Δ𝑝/ℏΔk=Δp/ℏDelta k = Delta p / hbar 代入上式，立刻直接推导出：

    Δ𝑥⋅Δ𝑝≥ℏ2Δx⋅Δp≥ℏ2Delta x * Delta p >= 2

    这深刻表明：测不准原理并非仪器测量精度的实验局限，而是波动力学与傅里叶变换的纯内在数学对称性！

    5. 跨模块物理应用

    5.1 夫琅禾费单缝衍射

    在物理光学中，夫琅禾费远场衍射光场的复振幅分布，数学上精确等于孔径透射率函数的 二维空间傅里叶变换．单缝矩形透射函数的傅里叶变换直接给出了衍射条纹的 sinc(𝑘)sinc(k)sinc(k) 分布．

    5.2 量子力学坐标表象与动量表象

    量子体系的波函数 𝜓(𝑥)ψ(x)psi(x) 与动量波函数 𝜙(𝑝)ϕ(p)phi(p) 互为傅里叶变换对：

    𝜙(𝑝)=1√2𝜋ℏ∫∞−∞𝜓(𝑥)exp⁡(−𝑖𝑝𝑥ℏ)d𝑥ϕ(p)=12πℏ∫−∞∞ψ(x)exp⁡(−ipxℏ)dxphi(p) = 12pihbar int_-inf^inf psi(x) expleft(-ipxhbarright) dx

    位置算符 ˆ𝑥x^x 与动量算符 ˆ𝑝 = −𝑖ℏdd𝑥p^=−iℏddxp = -ihbar ddx 的对易子 [ˆ𝑥,ˆ𝑝] =𝑖ℏ[x^,p^]=iℏ[x, p] = ihbar 正是傅里叶求导性质的算子化写照．
