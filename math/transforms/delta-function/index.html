    狄拉克 Delta 函数

    物理问题引入：如何用数学描述「没有体积的点电荷」？

    在宏观电磁学中，电荷密度定义为单位体积内的电荷量：𝜌 =Δ𝑞Δ𝑉ρ=ΔqΔVrho = Delta q/Delta V． 但是，经典电动力学常常研究 理想点电荷 𝑞qq：

    • 它集中在空间中一个没有体积的几何点 𝒓0r0r_0 处（Δ𝑉 →0ΔV→0Delta V -> 0）；
    • 在该点处，电荷密度应当发散到无穷大（𝜌(𝒓0) =∞ρ(r0)=∞rho(r_0) = inf）；
    • 在除该点之外的其余所有空间，电荷密度严格为零（𝜌(𝒓 ≠𝒓0) =0ρ(r≠r0)=0rho(r != r_0) = 0）；
    • 然而，当对包含该点的整个空间区域积分时，总电荷必须精确等于 𝑞qq：∭𝜌(𝒓)d𝑉 =𝑞∭ρ(r)dV=qiiint rho(r)dV = q．

    在传统柯西 - 黎曼积分体系中，一个「几乎处处为零」的函数其积分必然为零，根本无法容纳这种物理现实． 为了给点电荷、瞬间冲量、质点质量密度赋予合法的数学身份，保罗·狄拉克（Paul Dirac） 引入了 𝛿δdelta 函数（后由数学家施瓦茨建立为严格的 广义函数/分布（Distribution） 理论）．

    1. 狄拉克 𝛿δdelta 函数的定义与极限表示

    1.1 算子定义（筛选性定义）

    严格来说，𝛿(𝑥)δ(x)delta(x) 并非传统逐点定义的普通函数，而是一个作用于连续测试函数 𝑓(𝑥)f(x)f(x) 上的线性泛函：

    ∫∞−∞𝑓(𝑥)𝛿(𝑥−𝑎)d𝑥=𝑓(𝑎)∫−∞∞f(x)δ(x−a)dx=f(a)int_-inf^inf f(x) delta(x - a) dx = f(a)

    1.2 物理近似序列（弱收敛极限）

    在真实物理系统中，点源都是某种极端极限下的近似．𝛿(𝑥)δ(x)delta(x) 可视为下列光滑函数序列在参数 𝜖 →0ϵ→0epsilon -> 0 时的弱极限：

    1. 高斯函数极限：

      𝛿(𝑥)=lim𝜖→01√2𝜋𝜖exp⁡(−𝑥22𝜖2)δ(x)=limϵ→012πϵexp⁡(−x22ϵ2)delta(x) = lim_epsilon -> 0 12piepsilon expleft(-x^22epsilon^2right)

    2. 洛伦兹型（柯西分布）极限：

      𝛿(𝑥)=lim𝜖→01𝜋𝜖𝑥2+𝜖2δ(x)=limϵ→01πϵx2+ϵ2delta(x) = lim_epsilon -> 0 1pi x^2 + epsilon^2

    3. 波动与傅里叶积分核极限（狄利克雷核）：

      𝛿(𝑥)=lim𝐾→∞sin⁡(𝐾𝑥)𝜋𝑥=12𝜋∫∞−∞𝑒𝑖𝑘𝑥d𝑘δ(x)=limK→∞sin⁡(Kx)πx=12π∫−∞∞eikxdkdelta(x) = lim_K -> inf sin(K x)pi x = 12pi int_-inf^inf e^ikx dk

    3. 三维空间形式与正交坐标系表达

    在三维空间中，点源的三维狄拉克 𝛿δdelta 函数定义为笛卡尔分量的乘积：

    𝛿(𝒓−𝒓0)=𝛿(𝑥−𝑥0)𝛿(𝑦−𝑦0)𝛿(𝑧−𝑧0)δ(r−r0)=δ(x−x0)δ(y−y0)δ(z−z0)delta(r - r_0) = delta(x - x_0)delta(y - y_0)delta(z - z_0)

    满足全空间体积分归一性：∭ℝ3𝛿(𝒓 −𝒓0)d3𝒓 =1∭R3δ(r−r0)d3r=1iiint_R^3 delta(r - r_0)d^3r = 1．

    由于体积元在曲线坐标系中含有拉梅系数（Lamé coefficients）雅可比行列式 d𝑉 =ℎ1ℎ2ℎ3d𝑢1d𝑢2d𝑢3dV=h1h2h3du1du2du3dV = h_1 h_2 h_3 du_1 du_2 du_3：

      𝛿(𝒓−𝒓0)=1𝑟𝛿(𝑟−𝑟0)𝛿(𝜃−𝜃0)𝛿(𝑧−𝑧0)δ(r−r0)=1rδ(r−r0)δ(θ−θ0)δ(z−z0)delta(r - r_0) = 1r delta(r - r_0)delta(theta - theta_0)delta(z - z_0)

    4. 物理皇冠公式：泊松方程与基本解

    在经典静电学中，距原点 𝑟rr 处的单位点电荷激发的库仑势为 𝜙(𝒓) =14𝜋𝜀0𝑟ϕ(r)=14πε0rphi(r) = 14pivarepsilon_0 r． 在除原点外的任意位置：

    ∇2(1𝑟)=1𝑟2dd𝑟(𝑟2dd𝑟1𝑟)=1𝑟2dd𝑟(−1)=0∇2(1r)=1r2ddr(r2ddr1r)=1r2ddr(−1)=0nabla^2 left(1rright) = 1r^2ddrleft(r^2 ddr1rright) = 1r^2ddrleft(-1right) = 0

    然而，根据高斯散度定理，包围原点的任意闭合球面上电场通量为：

    ∮𝑆∇(1𝑟)⋅d𝑺=∮𝑆(−ˆ𝑟𝑟2)⋅(ˆ𝑟𝑟2dΩ)=−∮𝑆dΩ=−4𝜋∮S∇(1r)⋅dS=∮S(−r^r2)⋅(r^r2dΩ)=−∮SdΩ=−4πoint_S nablaleft(1rright)*dS = oint_S left(-rr^2right)* (r r^2 dOmega) = -oint_S dOmega = -4pi

    如果 ∇2(1/𝑟)∇2(1/r)nabla^2(1/r) 处处为零，根据散度定理体积分也应为零，这产生明显矛盾！ 唯一的解释是，原点处包含了集中发散的散度源．用 𝛿δdelta 函数表达这一深刻事实即为：

    ∇2(1|𝒓−𝒓′|)=−4𝜋𝛿(𝒓−𝒓′)∇2(1|r−r′|)=−4πδ(r−r′)nabla^2 left(1|r - r'|right) = -4pi delta(r - r')
    格林函数方法的诞生之门

    上式意味着：𝐺(𝒓,𝒓′) =14𝜋|𝒓−𝒓′|G(r,r′)=14π|r−r′|G(r, r') = 14pi|r - r'| 是拉普拉斯算符在三维无限大自由空间中的 格林函数！后续所有静电边值与电动力学积分，均源于这一个方程．
