    内积空间与希尔伯特空间

    内积空间与希尔伯特空间图景

    物理问题引入：如何度量两个量子态之间的「投影与重叠」？

    在三维空间几何中，点积 𝒖 ⋅𝒗 =|𝒖||𝒗|cos⁡𝜃u⋅v=|u||v|cos⁡θu*v = |u||v|costheta 定义了向量的长度与夹角． 在量子物理中：

    • 系统的状态由复态矢量 |𝜓⟩|ψ⟩|psirangle 描述；
    • 两个态矢量的「重叠程度」决定了从一个态跃迁到另一个态的 跃迁概率幅；
    • 任意微观量子态的发现概率必须满足归一化条件：∑𝑃𝑛 =1∑Pn=1sum P_n = 1．

    为了在包含复数甚至连续无穷维函数的空间中严格定义「长度」、「垂直正交」与「投影分解」，我们需要将初等几何点乘升华为 内积空间 (Inner Product Space) 与 希尔伯特空间 (Hilbert Space)．

    1. 复内积空间的公理化定义

    设 𝑉VV 是复数域 ℂCC 上的线性空间． 映射 ⟨ ⋅| ⋅⟩ :𝑉 ×𝑉 →ℂ⟨⋅|⋅⟩:V×V→Clangle * | * rangle: V * V -> C 称为 内积，如果它满足以下四条公理（采用理论物理通用的狄拉克左矢 ⟨𝒖|⟨u|langleu| 与右矢 |𝒗⟩|v⟩|vrangle 记号）：

    1. 共轭对称性：⟨𝒖|𝒗⟩ =⟨𝒗|𝒖⟩∗⟨u|v⟩=⟨v|u⟩∗langleu|vrangle = langlev|urangle^*；
    2. 对右矢严格线性：⟨𝒖|𝛼𝒗1 +𝛽𝒗2⟩ =𝛼⟨𝒖|𝒗1⟩ +𝛽⟨𝒖|𝒗2⟩⟨u|αv1+βv2⟩=α⟨u|v1⟩+β⟨u|v2⟩langleu| alphav_1 + betav_2 rangle = alphalangleu|v_1rangle + betalangleu|v_2rangle；
    3. 对左矢反线性（伴随共轭）：⟨𝛼𝒖1 +𝛽𝒖2|𝒗⟩ =𝛼∗⟨𝒖1|𝒗⟩ +𝛽∗⟨𝒖2|𝒗⟩⟨αu1+βu2|v⟩=α∗⟨u1|v⟩+β∗⟨u2|v⟩langle alphau_1 + betau_2 | vrangle = alpha^* langleu_1|vrangle + beta^* langleu_2|vrangle；
    4. 正定性：⟨𝒗|𝒗⟩ ≥0⟨v|v⟩≥0langlev|vrangle >= 0，且等号成立当且仅当 |𝒗⟩ =𝟎|v⟩=0|vrangle = 0．

    定义态矢量的 模长（范数） 为：

    ‖|𝒗⟩‖=√⟨𝒗|𝒗⟩‖|v⟩‖=⟨v|v⟩| |vrangle | = langlev|vrangle

    2. 柯西 - 施瓦茨不等式 (Cauchy-Schwarz Inequality)

    对于内积空间中的任意两个非零向量 |𝒖⟩,|𝒗⟩|u⟩,|v⟩|urangle, |vrangle：

    |⟨𝒖|𝒗⟩|2≤⟨𝒖|𝒖⟩⟨𝒗|𝒗⟩|⟨u|v⟩|2≤⟨u|u⟩⟨v|v⟩|langleu|vrangle|^2 <= langleu|urangle langlev|vrangle

    等号成立的充要条件是两向量线性相关（成常数倍比例）．

    量子力学广义不确定性关系的纯代数之门

    在量子力学中，任何两个可观测量算符 ˆ𝐴A^A 和 ˆ𝐵B^B 的方差涨落均方根 Δ𝐴 ⋅Δ𝐵ΔA⋅ΔBDelta A * Delta B，其证明的唯一关键核心数学工具正是柯西 - 施瓦茨不等式：

    (Δ𝐴)2(Δ𝐵)2≥14∣⟨[ˆ𝐴,ˆ𝐵]⟩∣2(ΔA)2(ΔB)2≥14|⟨[A^,B^]⟩|2(Delta A)^2 (Delta B)^2 >= 14 left| langle [A, B] rangle right|^2

    纯代数的内积不等式直接锁死了大自然一切量子对易测量的极限精度！

    3. 格拉姆 - 施密特正交化 (Gram-Schmidt Process)

    若空间中有一组线性无关基 {|𝒗1⟩,…,|𝒗𝑛⟩}{|v1⟩,…,|vn⟩}|v_1rangle, dots, |v_nrangle，可通过连续正交投影将其改造成一组 标准正交归一基 {|𝒆1⟩,…,|𝒆𝑛⟩}{|e1⟩,…,|en⟩}|e_1rangle, dots, |e_nrangle：

    |𝒖1⟩=|𝒗1⟩,|𝒆1⟩=|𝒖1⟩‖|𝒖1⟩‖|u1⟩=|v1⟩,|e1⟩=|u1⟩‖|u1⟩‖|u_1rangle = |v_1rangle, quad |e_1rangle = |u_1 | |u_1rangle ||𝒖𝑘⟩=|𝒗𝑘⟩−𝑘−1∑𝑗=1⟨𝒆𝑗|𝒗𝑘⟩|𝒆𝑗⟩,|𝒆𝑘⟩=|𝒖𝑘⟩‖|𝒖𝑘⟩‖(𝑘=2,…,𝑛)|uk⟩=|vk⟩−∑j=1k−1⟨ej|vk⟩|ej⟩,|ek⟩=|uk⟩‖|uk⟩‖(k=2,…,n)|u_krangle = |v_krangle - sum_j=1^k-1 langlee_j|v_krangle |e_jrangle, quad |e_krangle = |u_k | |u_krangle | quad (k = 2, dots, n)

    4. 希尔伯特空间图景与恒等算符完备分解

    4.1 希尔伯特空间 (Hilbert Space)

    定义在复内积空间上的序列若满足「柯西序列必收敛于空间内部点」，称为 完备的内积空间——即 希尔伯特空间 HHH．

    • 有限维希尔伯特空间：复空间 ℂ𝑛CnC^n（如两能级自旋体系，态矢为列向量，内积为 ⟨𝒖|𝒗⟩ =𝒖†𝒗⟨u|v⟩=u†vlangleu|vrangle = u^dagger v）；
    • 无限维希尔伯特空间：平方可积复函数空间 𝐿2(ℝ)L2(R)L^2(R)（如一维薛定谔波函数，内积定义为空间卷积积分：⟨𝜙|𝜓⟩ =∫∞−∞𝜙∗(𝑥)𝜓(𝑥)d𝑥⟨ϕ|ψ⟩=∫−∞∞ϕ∗(x)ψ(x)dxlanglephi|psirangle = int_-inf^inf phi^*(x)psi(x)dx）．

    4.2 恒等算符完备分解 (Resolution of the Identity)

    设 {|𝑛⟩}∞𝑛=1{|n⟩}n=1∞|nrangle _n=1^inf 为希尔伯特空间的一组标准正交归一基（满足 ⟨𝑚|𝑛⟩ =𝛿𝑚𝑛⟨m|n⟩=δmnlangle m|nrangle = delta_mn）． 任意态矢量 |𝜓⟩|ψ⟩|psirangle 均可展开为基矢量的投影求和：

    |𝜓⟩=∑𝑛𝑐𝑛|𝑛⟩=∑𝑛|𝑛⟩⟨𝑛|𝜓⟩=(∑𝑛|𝑛⟩⟨𝑛|)|𝜓⟩|ψ⟩=∑ncn|n⟩=∑n|n⟩⟨n|ψ⟩=(∑n|n⟩⟨n|)|ψ⟩|psirangle = sum_n c_n |nrangle = sum_n |nrangle langle n|psirangle = left( sum_n |nranglelangle n| right) |psirangle

    因为该式对任意态 |𝜓⟩|ψ⟩|psirangle 恒成立，括弧内的投影算符之和严格等于 单位恒等算符：

    ∑𝑛|𝑛⟩⟨𝑛|=ˆ𝐼∑n|n⟩⟨n|=I^sum_n |nranglelangle n| = I

    这被称作量子力学中最强大的「插入恒等式技巧」！
