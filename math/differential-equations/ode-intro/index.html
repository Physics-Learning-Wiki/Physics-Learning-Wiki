    常微分方程基础

    常微分方程基础与一阶方程

    物理问题引入：自然定律为什么总是写成微分方程？

    在物理学中，绝大多数基本物理定律（牛顿定律、麦克斯韦方程、热力学传导、薛定谔方程）并不是直接给出物理量本身（如位置 𝑥xx 或电荷 𝑞qq），而是给出物理量的 变化率：

    • 牛顿第二定律指出：加速度（位置随时间的二阶导数 d2𝑥d𝑡2d2xdt2d^2 xdt^2）正比于合外力；
    • 放射性原子核衰变指出：单位时间衰变的原子数（数量的一阶导数 d𝑁d𝑡dNdtdNdt）正比于当前存在的原子核总数；
    • 欧姆与法拉第定律指出：感应电动势正比于磁通量的变化率．

    将物理量及其各阶导数联系起来的方程，就是 微分方程 (Differential Equations)．当未知函数仅依赖于 单一自变量（如仅依赖时间 𝑡tt 或空间单坐标 𝑥xx）时，称为 常微分方程 (ODE)．

    1. 常微分方程的基本概念与分类

    1.1 阶数与线性

    一般 𝑛nn 阶常微分方程形式为：

    𝐹(𝑥,𝑦,𝑦′,𝑦″,…,𝑦(𝑛))=0F(x,y,y′,y″,…,y(n))=0Fleft(x, y, y', y'', dots, y^(n)right) = 0
    • 阶数 (Order)：方程中出现的最高阶导数次数 𝑛nn；

    • 线性 (Linear)：未知函数 𝑦yy 及其所有导数 𝑦′,𝑦″,…y′,y″,…y', y'', dots 均以一次幂出现，且彼此没有交叉相乘项．线性方程的一般形式为：

      𝑎𝑛(𝑥)𝑦(𝑛)+⋯+𝑎1(𝑥)𝑦′+𝑎0(𝑥)𝑦=𝑓(𝑥)an(x)y(n)+⋯+a1(x)y′+a0(x)y=f(x)a_n(x) y^(n) + dots + a_1(x) y' + a_0(x) y = f(x)

      若非齐次项 𝑓(𝑥) =0f(x)=0f(x) = 0，称为 齐次方程；反之称为 非齐次方程．

    1.2 通解与特解

    • 通解：包含与方程阶数相同数目的独立任意常数（𝐶1,…,𝐶𝑛C1,…,CnC_1, dots, C_n）的解族；
    • 特解：通过实验给定的 初始条件（如 𝑡 =0t=0t=0 时的位置与速度）唯一确定常数后的解．

    2. 常见一阶常微分方程的求解范式

    一阶方程的标准形式为 d𝑦d𝑥 =𝑓(𝑥,𝑦)dydx=f(x,y)dydx = f(x, y)．

    2.1 分离变量法 (Separation of Variables)

    若方程右端可分解为 𝑥xx 与 𝑦yy 函数的乘积：

    d𝑦d𝑥=𝑔(𝑥)ℎ(𝑦)⟹d𝑦ℎ(𝑦)=𝑔(𝑥)d𝑥dydx=g(x)h(y)⟹dyh(y)=g(x)dxdydx = g(x) h(y) implies dyh(y) = g(x) dx

    两边直接积分即得通解：∫d𝑦ℎ(𝑦) =∫𝑔(𝑥)d𝑥 +𝐶∫dyh(y)=∫g(x)dx+Cint dyh(y) = int g(x)dx + C．

    2.2 一阶线性微分方程与积分因子法

    标准一阶线性方程形式为：

    d𝑦d𝑥+𝑃(𝑥)𝑦=𝑄(𝑥)dydx+P(x)y=Q(x)dydx + P(x)y = Q(x)

    引入积分因子 𝜇(𝑥) =exp⁡(∫𝑃(𝑥)d𝑥)μ(x)=exp⁡(∫P(x)dx)mu(x) = expleft(int P(x)dxright)，方程左边可重写为全导数：

    dd𝑥[𝑦𝑒∫𝑃(𝑥)d𝑥]=𝑄(𝑥)𝑒∫𝑃(𝑥)d𝑥ddx[ye∫P(x)dx]=Q(x)e∫P(x)dxddxleft[ y e^int P(x)dx right] = Q(x) e^int P(x)dx

    两边积分直接得到通解公式（常数变易法结果）：

    𝑦(𝑥)=exp⁡(−∫𝑃(𝑥)d𝑥)[∫𝑄(𝑥)exp⁡(∫𝑃(𝑥)d𝑥)d𝑥+𝐶]y(x)=exp⁡(−∫P(x)dx)[∫Q(x)exp⁡(∫P(x)dx)dx+C]y(x) = expleft(-int P(x)dxright) left[ int Q(x) expleft(int P(x)dxright) dx + C right]

    3. 物理建模例题：带黏性阻力的雨滴下落与收尾速度

    物理问题：质量为 𝑚mm 的雨滴在重力场中自静止下落，空气阻力与瞬时速度成正比：𝑓drag = −𝑏𝑣fdrag=−bvf_drag = -b v．求雨滴速度随时间演化的规律及收尾速度．

    建模与求解

    选取向下为正方向，根据牛顿第二定律：

    𝑚d𝑣d𝑡=𝑚𝑔−𝑏𝑣⟹d𝑣d𝑡+𝑏𝑚𝑣=𝑔mdvdt=mg−bv⟹dvdt+bmv=gm dvdt = mg - bv implies dvdt + bmv = g

    这是一阶线性常系数微分方程，满足 𝑃(𝑡) =𝑏𝑚,𝑄(𝑡) =𝑔P(t)=bm,Q(t)=gP(t) = b/m, Q(t) = g． 分离变量或利用通解公式：

    d𝑣𝑔−𝑏𝑚𝑣=d𝑡⟹−𝑚𝑏ln⁡∣𝑔−𝑏𝑚𝑣∣=𝑡+𝐶0dvg−bmv=dt⟹−mbln⁡|g−bmv|=t+C0dvg - bmv = dt implies -mb lnleft|g - bmvright| = t + C_0

    取指数并利用初值条件 𝑣(0) =0v(0)=0v(0) = 0：

    𝑣(𝑡)=𝑚𝑔𝑏(1−exp⁡(−𝑏𝑚𝑡))v(t)=mgb(1−exp⁡(−bmt))v(t) = mgbleft( 1 - expleft(-bmtright) right)

    结果物理分析

    • 特征弛豫时间：𝜏 =𝑚𝑏τ=mbtau = mb，系统在该时间内完成主要加速；

    • 收尾速度 (Terminal Velocity)：当 𝑡 ≫𝜏t≫τt gg tau 时，指数衰减项趋近于零，重力与空气阻力达成动力学平衡，速度趋向稳定极限：

      𝑣terminal=lim𝑡→∞𝑣(𝑡)=𝑚𝑔𝑏vterminal=limt→∞v(t)=mgbv_terminal = lim_t -> inf v(t) = mgb
