    偏微分方程分离变量法

    偏微分方程分离变量法

    物理问题引入：两端固定的弦为什么只允许特定频率振荡？

    考察一根长度为 𝐿LL、两端牢固固定的吉他弦：

    • 在宏观上，你可以用拨片随意拨出各种奇怪的初始折线形状 𝑢(𝑥,0) =𝜙(𝑥)u(x,0)=ϕ(x)u(x, 0) = phi(x)；
    • 但在波动动力学演化中，琴弦 绝不能 以任意连续频率振动；
    • 物理测量显示，琴弦的声音必定由 𝑓1 =𝑣2𝐿,𝑓2 =2𝑓1,𝑓3 =3𝑓1,…f1=v2L,f2=2f1,f3=3f1,…f_1 = v/2L, f_2 = 2f_1, f_3 = 3f_1, dots 等一组 严格分立的特征基频与泛音 构成．

    为什么连续的偏微分方程 𝜕2𝑢𝜕𝑥2 =1𝑣2𝜕2𝑢𝜕𝑡2∂2u∂x2=1v2∂2u∂t2d^2 ud x^2 = 1v^2d^2 ud t^2 会自动筛选出这组分立的离散频率？分离变量法 (Separation of Variables，又称傅里叶法） 揭示了这一奇迹背后的全部数学奥秘．

    1. 分离变量法四步通用范式

    以最典型的一维有限长弦齐次波动定解问题为例：

    第一步：设乘积解，变量解耦

    假设未知场函数可以分解为纯空间因子与纯时间因子的乘积：

    𝑢(𝑥,𝑡)=𝑋(𝑥)𝑇(𝑡)u(x,t)=X(x)T(t)u(x, t) = X(x) T(t)

    代入波动方程：𝑋(𝑥)𝑇″(𝑡) =𝑣2𝑋″(𝑥)𝑇(𝑡)X(x)T″(t)=v2X″(x)T(t)X(x) T''(t) = v^2 X''(x) T(t)．两边同除以 𝑣2𝑋(𝑥)𝑇(𝑡)v2X(x)T(t)v^2 X(x) T(t)：

    𝑋″(𝑥)𝑋(𝑥)=1𝑣2𝑇″(𝑡)𝑇(𝑡)X″(x)X(x)=1v2T″(t)T(t)X''(x)X(x) = 1v^2T''(t)T(t)

    等式左边只依赖于空间坐标 𝑥xx，等式右边只依赖于时间 𝑡tt．要让这两个完全独立的自变量在任意时刻、任意地点处处相等，它们必须共同等于同一个与 𝑥,𝑡x,tx, t 均无关的常数，记为 −𝜆−λ-lambda（分离常数）：

    𝑋″(𝑥)𝑋(𝑥)=−𝜆⟹𝑋″(𝑥)+𝜆𝑋(𝑥)=0X″(x)X(x)=−λ⟹X″(x)+λX(x)=0X''(x)X(x) = -lambda implies X''(x) + lambda X(x) = 0𝑇″(𝑡)𝑇(𝑡)=−𝑣2𝜆⟹𝑇″(𝑡)+𝑣2𝜆𝑇(𝑡)=0T″(t)T(t)=−v2λ⟹T″(t)+v2λT(t)=0T''(t)T(t) = -v^2 lambda implies T''(t) + v^2 lambda T(t) = 0

    偏微分方程被成功降阶为两个独立的常微分方程！

    第二步：结合齐次边界，求解空间本征值问题

    齐次边界条件给出：𝑢(0,𝑡) =𝑋(0)𝑇(𝑡) =0 ⟹ 𝑋(0) =0u(0,t)=X(0)T(t)=0⟹X(0)=0u(0, t) = X(0)T(t) = 0 implies X(0) = 0；同理 𝑋(𝐿) =0X(L)=0X(L) = 0． 由此得到空间常微分方程的 边值问题（又称 Sturm–Liouville 本征值问题）：

    𝑋″(𝑥)+𝜆𝑋(𝑥)=0,𝑋(0)=0,𝑋(𝐿)=0X″(x)+λX(x)=0,X(0)=0,X(L)=0X''(x) + lambda X(x) = 0, quad X(0) = 0, quad X(L) = 0

    分类讨论分离常数 𝜆λlambda：

    1. 若 𝜆 <0λ<0lambda < 0 或 𝜆 =0λ=0lambda = 0，通解为双曲函数或线性函数，代入两端边界只能得到平凡零解 𝑋(𝑥) ≡0X(x)≡0X(x) equiv 0（弦完全不振动，无物理意义）；
    2. 若 𝜆 >0λ>0lambda > 0，令 𝜆 =𝑘2λ=k2lambda = k^2，通解为：𝑋(𝑥) =𝐶1cos⁡(𝑘𝑥) +𝐶2sin⁡(𝑘𝑥)X(x)=C1cos⁡(kx)+C2sin⁡(kx)X(x) = C_1 cos(kx) + C_2 sin(kx)．
      • 𝑋(0) =0 ⟹ 𝐶1 =0X(0)=0⟹C1=0X(0) = 0 implies C_1 = 0；
      • 𝑋(𝐿) =𝐶2sin⁡(𝑘𝐿) =0X(L)=C2sin⁡(kL)=0X(L) = C_2 sin(k L) = 0．

    为了得到非零解，必须满足正弦函数零点条件：𝑘𝐿 =𝑛𝜋kL=nπk L = npi(𝑛 =1,2,3,…n=1,2,3,…n = 1, 2, 3, dots)． 由此，边界条件强制筛选出一组 离散分立的特征值（本征值）与本征函数：

    𝜆𝑛=(𝑛𝜋𝐿)2,𝑋𝑛(𝑥)=sin⁡(𝑛𝜋𝑥𝐿)(𝑛=1,2,3,…)λn=(nπL)2,Xn(x)=sin⁡(nπxL)(n=1,2,3,…)lambda_n = left(nLright)^2, quad X_n(x) = sinleft(npi xLright) quad (n = 1, 2, 3, dots)

    第三步：求解时间方程，构造简正模

    将求得的特征值 𝜆𝑛λnlambda_n 代回时间常微分方程：

    𝑇″𝑛(𝑡)+𝜔2𝑛𝑇𝑛(𝑡)=0,其中 𝜔𝑛=𝑣√𝜆𝑛=𝑛𝜋𝑣𝐿Tn″(t)+ωn2Tn(t)=0,其中 ωn=vλn=nπvLT_n''(t) + omega_n^2 T_n(t) = 0, quad 其中 omega_n = vlambda_n = npi vL

    解出时间演化为单频正弦简谐振荡：

    𝑇𝑛(𝑡)=𝐴𝑛cos⁡(𝜔𝑛𝑡)+𝐵𝑛sin⁡(𝜔𝑛𝑡)Tn(t)=Ancos⁡(ωnt)+Bnsin⁡(ωnt)T_n(t) = A_n cos(omega_n t) + B_n sin(omega_n t)

    将空间本征函数与时间解相乘，得到满足方程和齐次边界的特定特解——物理驻波简正模态 (Normal Modes)：

    𝑢𝑛(𝑥,𝑡)=𝑋𝑛(𝑥)𝑇𝑛(𝑡)=[𝐴𝑛cos⁡(𝜔𝑛𝑡)+𝐵𝑛sin⁡(𝜔𝑛𝑡)]sin⁡(𝑛𝜋𝑥𝐿)un(x,t)=Xn(x)Tn(t)=[Ancos⁡(ωnt)+Bnsin⁡(ωnt)]sin⁡(nπxL)u_n(x, t) = X_n(x) T_n(t) = left[ A_n cos(omega_n t) + B_n sin(omega_n t) right] sinleft(npi xLright)

    每一个驻波模态都具有固定的空间波节分布和纯粹的单色频率 𝜔𝑛ωnomega_n！

    第四步：线性叠加，满足非齐次初始条件

    根据线性叠加原理，一般通解由所有简正模态的无穷级数求和给出：

    𝑢(𝑥,𝑡)=∞∑𝑛=1[𝐴𝑛cos⁡(𝜔𝑛𝑡)+𝐵𝑛sin⁡(𝜔𝑛𝑡)]sin⁡(𝑛𝜋𝑥𝐿)u(x,t)=∑n=1∞[Ancos⁡(ωnt)+Bnsin⁡(ωnt)]sin⁡(nπxL)u(x, t) = sum_n=1^inf left[ A_n cos(omega_n t) + B_n sin(omega_n t) right] sinleft(npi xLright)

    代入初值条件：

    1. 初始位移：𝑢(𝑥,0) =∑∞𝑛=1𝐴𝑛sin⁡(𝑛𝜋𝑥𝐿) =𝜙(𝑥)u(x,0)=∑n=1∞Ansin⁡(nπxL)=ϕ(x)u(x, 0) = sum_n=1^inf A_n sinleft(npi xLright) = phi(x)；
    2. 初始速度：𝜕𝑢𝜕𝑡∣𝑡=0 =∑∞𝑛=1(𝐵𝑛𝜔𝑛)sin⁡(𝑛𝜋𝑥𝐿) =𝜓(𝑥)∂u∂t|t=0=∑n=1∞(Bnωn)sin⁡(nπxL)=ψ(x)left.d ud tright|_t=0 = sum_n=1^inf (B_n omega_n) sinleft(npi xLright) = psi(x)．

    这正是本征基底 sin⁡(𝑛𝜋𝑥𝐿)sin⁡(nπxL)sinleft(npi x/Lright) 的 傅里叶正弦级数展开！利用正交性直接求出振幅系数：

    𝐴𝑛=2𝐿∫𝐿0𝜙(𝑥)sin⁡(𝑛𝜋𝑥𝐿)d𝑥An=2L∫0Lϕ(x)sin⁡(nπxL)dxA_n = 2L int_0^L phi(x) sinleft(npi xLright) dx𝐵𝑛=2𝑛𝜋𝑣∫𝐿0𝜓(𝑥)sin⁡(𝑛𝜋𝑥𝐿)d𝑥Bn=2nπv∫0Lψ(x)sin⁡(nπxL)dxB_n = 2npi v int_0^L psi(x) sinleft(npi xLright) dx

    至此，定解问题获得唯一确定的解析级数通解！

    2. 分离变量法通向现代物理的中枢地位

    分离变量法绝不局限于笛卡尔坐标下的正弦函数：

    1. 圆对称体系（柱坐标）：拉普拉斯算子分离出的径向本征方程是 贝塞尔方程，导出的本征函数是 贝塞尔函数 𝐽𝑚(𝑘𝑟)Jm(kr)J_m(kr)；
    2. 球对称体系（球坐标）：角向本征方程是 勒让德方程，本征函数是 球谐函数 𝑌𝑚𝑙(𝜃,𝜙)Ylm(θ,ϕ)Y_l^m(theta, phi)；
    3. 量子定态薛定谔方程：波函数做空间 - 时间分离 Ψ(𝒓,𝑡) =𝜓(𝒓)𝑒−𝑖𝐸𝑡/ℏΨ(r,t)=ψ(r)e−iEt/ℏPsi(r, t) = psi(r) e^-iEt/hbar，空间本征方程 ˆ𝐻𝜓 =𝐸𝜓H^ψ=EψHpsi = Epsi 就是最标准的分离变量产物！

    所有这些不同的几何方程，在深层数学结构上全部统一于一个宏伟理论——Sturm–Liouville 本征值理论．
