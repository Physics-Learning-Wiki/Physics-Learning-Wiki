    概率论的基本概念

    概率论的基本概念

    概率论是研究随机现象的数学分支．在物理学中，它是统计力学的数学语言——描述平衡态下粒子分布的核心工具．在学习麦克斯韦速率分布律之前，我们需要先建立概率论的基本框架：什么是随机事件？如何度量概率？已知部分信息时如何更新概率判断？

    学习目标

    读完本页后，你应该能够：

    • 理解样本空间、事件和概率的定义
    • 掌握概率的三条柯尔莫哥洛夫公理
    • 计算条件概率，理解事件的独立性
    • 运用全概率公式和贝叶斯公式解决实际问题

    随机实验与样本空间

    在物理学和日常生活中，我们经常遇到结果不确定的现象：抛一枚硬币是正面还是反面？放射性原子在下一秒是否衰变？这些现象的共同特点是：单次实验的结果无法预测，但大量重复实验会呈现出统计规律性．

    样本空间

    一个 随机实验 的所有可能结果组成的集合称为 样本空间（Sample Space），记作 ΩΩOmega．样本空间中的每个元素 𝜔 ∈Ωω∈Ωomega in Omega 称为一个 样本点．

    • 有限样本空间：抛一枚硬币，Ω ={正面,反面}Ω={正面,反面}Omega = 正面, 反面
    • 可数无穷样本空间：记录放射性衰变的次数，Ω ={0,1,2,…}Ω={0,1,2,…}Omega = 0, 1, 2, dots
    • 不可数无穷样本空间：测量分子的速率，Ω =[0, +∞)Ω=[0,+∞)Omega = [0, +inf)

    事件（Event）是样本空间的一个子集 𝐴 ⊆ΩA⊆ΩA subseteq Omega．例如，"分子速率在 300 到 500 m/s 之间" 对应集合 𝐴 ={𝑣 ∈Ω :300 ≤𝑣 ≤500}A={v∈Ω:300≤v≤500}A = v in Omega : 300 <= v <= 500．

    两个特殊的事件：

    • 必然事件：ΩΩOmega 本身，每次实验一定发生
    • 不可能事件：空集 ∅∅varnothing，每次实验一定不发生

    事件之间的运算遵循集合运算规则：

    运算含义物理例子
    𝐴 ∪𝐵A∪BA cup B𝐴AA 或 𝐵BB 至少一个发生速率 <300 或> 500
    𝐴 ∩𝐵A∩BA cap B𝐴AA 和 𝐵BB 同时发生300 ≤ 速率 ≤ 500 且方向向上
    ¯𝐴A¯A𝐴AA 不发生速率不在 [300, 500] 内
    𝐴 ⊂𝐵A⊂BA subset B𝐴AA 发生则 𝐵BB 必然发生速率在 [300, 400] 内 → 速率在 [300, 500] 内

    概率的定义与公理

    概率是对事件发生可能性大小的数值度量．历史上，概率的定义经历了从频率解释到公理化体系的发展．

    频率解释

    在相同条件下重复进行 𝑛nn 次实验，事件 𝐴AA 发生了 𝑛𝐴nAn_A 次，则 𝐴AA 发生的 频率 为 𝑓𝐴 =𝑛𝐴/𝑛fA=nA/nf_A = n_A / n．当 𝑛nn 很大时，频率趋于一个稳定的值，这个稳定值就是概率的频率解释．

    例如，抛一枚均匀硬币，当抛掷次数足够多时，正面朝上的频率趋近于 0.50.50.5．

    柯尔莫哥洛夫公理

    1933 年，柯尔莫哥洛夫提出了概率的公理化定义，将概率建立在严格的数学基础之上．

    概率公理（柯尔莫哥洛夫公理）

    设 ΩΩOmega 为样本空间，对每个事件 𝐴 ⊆ΩA⊆ΩA subseteq Omega，定义一个实数 𝑃(𝐴)P(A)P(A)，满足以下三条公理：

    1. 非负性：对任意事件 𝐴AA，𝑃(𝐴) ≥0P(A)≥0P(A) >= 0
    2. 归一化：𝑃(Ω) =1P(Ω)=1P(Omega) = 1
    3. 可加性：若 𝐴1,𝐴2,…A1,A2,…A_1, A_2, dots 是两两不相交的事件（即 𝐴𝑖 ∩𝐴𝑗 =∅Ai∩Aj=∅A_i cap A_j = varnothing，𝑖 ≠𝑗i≠ji != j），则
    𝑃(∞⋃𝑖=1𝐴𝑖)=∞∑𝑖=1𝑃(𝐴𝑖)P(⋃i=1∞Ai)=∑i=1∞P(Ai)P !left(bigcup_i=1^inf A_iright) = sum_i=1^inf P(A_i)

    从这三条公理可以推导出概率的基本性质：

    • 𝑃(∅) =0P(∅)=0P(varnothing) = 0
    • 𝑃(¯𝐴) =1 −𝑃(𝐴)P(A¯)=1−P(A)P(A) = 1 - P(A)（互补事件）
    • 若 𝐴 ⊂𝐵A⊂BA subset B，则 𝑃(𝐴) ≤𝑃(𝐵)P(A)≤P(B)P(A) <= P(B)
    • 𝑃(𝐴 ∪𝐵) =𝑃(𝐴) +𝑃(𝐵) −𝑃(𝐴 ∩𝐵)P(A∪B)=P(A)+P(B)−P(A∩B)P(A cup B) = P(A) + P(B) - P(A cap B)（加法公式）

    等可能模型（古典概型）

    若样本空间 ΩΩOmega 为有限集，且每个样本点出现的可能性相等，则：

    𝑃(𝐴)=|𝐴||Ω|=𝐴 包含的样本点数总样本点数P(A)=|A||Ω|=A 包含的样本点数总样本点数P(A) = |A||Omega| = A 包含的样本点数总样本点数
    例题：掷骰子的概率

    题目：掷一颗均匀骰子，求点数为偶数的概率．

    解答：样本空间 Ω ={1,2,3,4,5,6}Ω={1,2,3,4,5,6}Omega = 1, 2, 3, 4, 5, 6，事件 𝐴 ={2,4,6}A={2,4,6}A = 2, 4, 6．由等可能模型：

    𝑃(𝐴)=|𝐴||Ω|=36=12P(A)=|A||Ω|=36=12P(A) = |A||Omega| = 36 = 12

    条件概率

    在实际问题中，我们往往已经知道某些信息（事件 𝐵BB 已经发生），在此基础上判断另一事件 𝐴AA 发生的概率．

    条件概率

    在事件 𝐵BB 已经发生（𝑃(𝐵) >0P(B)>0P(B) > 0）的条件下，事件 𝐴AA 发生的 条件概率 定义为：

    𝑃(𝐴|𝐵)=𝑃(𝐴∩𝐵)𝑃(𝐵)P(A|B)=P(A∩B)P(B)P(A|B) = P(A cap B)P(B)

    条件概率 𝑃(𝐴|𝐵)P(A|B)P(A|B) 本质上是在 𝐵BB 确定发生的新样本空间中，𝐴AA 与 𝐵BB 交集所占的比例．

    由条件概率的定义可以直接得到 乘法公式：

    𝑃(𝐴∩𝐵)=𝑃(𝐴|𝐵)⋅𝑃(𝐵)=𝑃(𝐵|𝐴)⋅𝑃(𝐴)P(A∩B)=P(A|B)⋅P(B)=P(B|A)⋅P(A)P(A cap B) = P(A|B) * P(B) = P(B|A) * P(A)

    独立性

    如果事件 𝐴AA 的发生不影响事件 𝐵BB 的概率，即 𝑃(𝐴|𝐵) =𝑃(𝐴)P(A|B)=P(A)P(A|B) = P(A)，则称 𝐴AA 和 𝐵BB 相互独立．此时乘法公式简化为：

    𝑃(𝐴∩𝐵)=𝑃(𝐴)⋅𝑃(𝐵)P(A∩B)=P(A)⋅P(B)P(A cap B) = P(A) * P(B)
    独立与互斥的区别
    • 互斥（𝐴 ∩𝐵 =∅A∩B=∅A cap B = varnothing）：𝐴AA 和 𝐵BB 不能同时发生．此时 𝑃(𝐴 ∩𝐵) =0P(A∩B)=0P(A cap B) = 0．
    • 独立：𝐴AA 的发生不影响 𝐵BB 的概率．此时 𝑃(𝐴 ∩𝐵) =𝑃(𝐴) ⋅𝑃(𝐵)P(A∩B)=P(A)⋅P(B)P(A cap B) = P(A) * P(B)．

    互斥和独立是两个不同的概念！互斥的事件一定不独立（如果 𝐴AA 发生了，𝐵BB 一定不发生，概率从 𝑃(𝐵)P(B)P(B) 变为 000）．

    全概率公式与贝叶斯公式

    全概率公式

    设 𝐵1,𝐵2,…,𝐵𝑛B1,B2,…,BnB_1, B_2, dots, B_n 是样本空间的一个 完备事件组（即两两不相交且 ⋃𝑖𝐵𝑖 =Ω⋃iBi=Ωbigcup_i B_i = Omega），则对任意事件 𝐴AA：

    𝑃(𝐴)=𝑛∑𝑖=1𝑃(𝐴|𝐵𝑖)⋅𝑃(𝐵𝑖)P(A)=∑i=1nP(A|Bi)⋅P(Bi)P(A) = sum_i=1^n P(A|B_i) * P(B_i)

    全概率公式的直观含义：要计算 𝐴AA 的总概率，可以按不同 "原因"𝐵𝑖BiB_i 分别考虑，再加权求和．

    贝叶斯公式

    贝叶斯公式

    在事件 𝐴AA 已经发生的条件下，"原因"𝐵𝑗BjB_j 发生的概率为：

    𝑃(𝐵𝑗|𝐴)=𝑃(𝐴|𝐵𝑗)⋅𝑃(𝐵𝑗)𝑛∑𝑖=1𝑃(𝐴|𝐵𝑖)⋅𝑃(𝐵𝑖)P(Bj|A)=P(A|Bj)⋅P(Bj)∑i=1nP(A|Bi)⋅P(Bi)P(B_j|A) = P(A|B_j) * P(B_j)displaystylesum_i=1^n P(A|B_i) * P(B_i)

    其中：

    • 𝑃(𝐵𝑗)P(Bj)P(B_j) 是 先验概率：在观测到 𝐴AA 之前，对原因 𝐵𝑗BjB_j 的概率判断
    • 𝑃(𝐵𝑗|𝐴)P(Bj|A)P(B_j|A) 是 后验概率：在观测到 𝐴AA 之后，对原因 𝐵𝑗BjB_j 的更新判断
    • 𝑃(𝐴|𝐵𝑗)P(A|Bj)P(A|B_j) 是 似然：在原因 𝐵𝑗BjB_j 成立的条件下，观测到 𝐴AA 的概率

    贝叶斯公式的核心意义在于：它给出了 "由果溯因" 的数学方法——已知观测结果，反推各个可能原因的概率．

    例题：放射性源的判断

    题目：实验室有两个放射性源．源 1 每秒平均发射 4 个粒子，源 2 每秒平均发射 1 个粒子．随机选取一个源进行观测，在下一秒内记录到 3 个粒子．假设粒子发射服从泊松分布，求所选源为源 1 的后验概率．（先验概率各为 1/21/21/2．）

    解答：设 𝐵1B1B_1= "选到源 1"，𝐵2B2B_2= "选到源 2"，𝐴AA= "记录到 3 个粒子"．

    由泊松分布 𝑃(𝑋 =𝑘) =𝜆𝑘𝑒−𝜆𝑘!P(X=k)=λke−λk!P(X=k) = lambda^k e^-lambdak!：

    𝑃(𝐴|𝐵1)=43𝑒−43!=64𝑒−46≈0.1954P(A|B1)=43e−43!=64e−46≈0.1954P(A|B_1) = 4^3 e^-43! = 64 e^-46 ~ 0.1954 𝑃(𝐴|𝐵2)=13𝑒−13!=𝑒−16≈0.0613P(A|B2)=13e−13!=e−16≈0.0613P(A|B_2) = 1^3 e^-13! = e^-16 ~ 0.0613

    由贝叶斯公式：

    𝑃(𝐵1|𝐴)=𝑃(𝐴|𝐵1)⋅𝑃(𝐵1)𝑃(𝐴|𝐵1)⋅𝑃(𝐵1)+𝑃(𝐴|𝐵2)⋅𝑃(𝐵2)=0.1954×0.50.1954×0.5+0.0613×0.5≈0.761P(B1|A)=P(A|B1)⋅P(B1)P(A|B1)⋅P(B1)+P(A|B2)⋅P(B2)=0.1954×0.50.1954×0.5+0.0613×0.5≈0.761P(B_1|A) = P(A|B_1) * P(B_1)P(A|B_1) * P(B_1) + P(A|B_2) * P(B_2) = 0.1954 * 0.50.1954 * 0.5 + 0.0613 * 0.5 ~ 0.761

    讨论：观测到 3 个粒子后，源 1 的后验概率从先验的 0.50.50.5 上升到约 0.760.760.76——因为 3 个粒子更符合源 1 的发射特征（平均 4 个）而非源 2（平均 1 个）．这正是贝叶斯更新的力量：用新的观测数据修正先前的判断．
