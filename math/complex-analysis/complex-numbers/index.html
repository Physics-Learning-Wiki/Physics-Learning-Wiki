    复数与几何表示

    物理问题引入：为什么实数物理世界需要虚数 𝑖ii？

    在日常经验中，长度、速度、温度、电荷、质量等所有可以直接测量的宏观物理量都是实数．既然如此，为什么理论物理学家在经典力学振动、电磁波动理论、流体力学以及量子力学中无处不在地使用虚数单位 𝑖 =√−1i=−1i = -1？

    “The shortest path between two truths in the real domain passes through the complex domain.” —— Jacques Hadamard
    （联系两个实数领域中真理的最短路径往往穿过复数领域．）

    两个决定性的原因回答了这个问题：

    1. 将多变量初等三角振动降维为单变量代数运算：
      一个简谐振动的质点同时具有振幅 𝐴AA 和初始相位 𝜙ϕphi．在实数三角函数框架下，两个不同相位简谐振动的合成与叠加需要调用繁杂的和差化积公式；而一旦引入复指数 𝑒𝑖𝜔𝑡eiωte^iomega t，时间和相位的演化直接转化为复数的乘除代数，微分方程被彻底化为代数方程；
    2. 量子力学的本质内在要求：
      正如诺贝尔物理学奖得主杨振宁先生在《虚数与量子力学》中所指出的，量子力学中的状态函数 𝜓(𝒓,𝑡)ψ(r,t)psi(r, t) 是本质性的复数场，单粒子薛定谔方程显式包含虚数单位 𝑖ℏ𝜕𝜓𝜕𝑡 =ˆ𝐻𝜓iℏ∂ψ∂t=H^ψihbar dpsi/d t = Hpsi．复概率幅的干涉使得微观粒子的空间几率密度必须通过双线性的模长平方 𝜌 =|𝜓|2 =𝜓∗𝜓ρ=|ψ|2=ψ∗ψrho = |psi|^2 = psi^* psi 来描述．

    1. 复数的数系扩充历史与代数结构

    1.1 从一元三次方程到阿根图复平面

    历史上，虚数并不是为了解一元二次方程 𝑥2 +1 =0x2+1=0x^2 + 1 = 0 凭空发明的，而是在 16 世纪意大利数学家卡尔达诺（Cardano）与塔塔利亚（Tartaglia）求解一元三次方程 𝑥3 =𝑝𝑥 +𝑞x3=px+qx^3 = px + q 的争论中不得不正视的存在．即使一个三次方程的三个根全部是实数，使用卡尔达诺公式时依然必须通过中间含有负数平方根的表达式（称为“不可约情形”）．1572 年，邦贝利（Bombelli）在其著作《代数学》中首次系统制定了虚数单位的运算法则．

    随后，欧拉（Euler）引入了符号 𝑖 =√−1i=−1i = -1，高斯（Gauss）与阿根（Argand）正式建立了复平面（Complex Plane / 阿根图），彻底赋予了虚数严谨的直角坐标几何含义．

    1.2 复数定义与基本四则运算

    定义：一个复数 𝑧zz 由一对有序实数 (𝑥,𝑦)(x,y)(x, y) 与虚数单位 𝑖ii 线性组合而成：

    𝑧=𝑥+𝑖𝑦(𝑥,𝑦∈ℝ)z=x+iy(x,y∈R)z = x + iy quad (x, y in R)

    其中： - 𝑥 =Re⁡(𝑧)x=Re⁡(z)x = Re(z) 称为复数 𝑧zz 的 实部 (Real Part)； - 𝑦 =Im⁡(𝑧)y=Im⁡(z)y = Im(z) 称为复数 𝑧zz 的 虚部 (Imaginary Part)．注意虚部本身是实数．

    实数的所有运算法则在复数域中保持完全有效，唯一的新增公理是虚数单位满足：

    𝑖2=−1,𝑖3=−𝑖,𝑖4=1,𝑖4𝑘+𝑛=𝑖𝑛(𝑘∈ℤ)i2=−1,i3=−i,i4=1,i4k+n=in(k∈Z)i^2 = -1, quad i^3 = -i, quad i^4 = 1, quad i^4k+n = i^n quad (k in Z)

    设有两个复数 𝑧1 =𝑥1 +𝑖𝑦1z1=x1+iy1z_1 = x_1 + i y_1，𝑧2 =𝑥2 +𝑖𝑦2z2=x2+iy2z_2 = x_2 + i y_2：

    • 加减法：实部虚部分别相加减：

    $$ z_1 \pm z_2 = (x_1 \pm x_2) + i(y_1 \pm y_2) $$

    • 乘法：按多项式乘法展开并利用 𝑖2 = −1i2=−1i^2 = -1：

    $$ z_1 z_2 = (x_1 x_2 - y_1 y_2) + i(x_1 y_2 + x_2 y_1) $$

    • 除法（分子分母同乘分母的共轭复数实现“分母实数化”）：

    $$ \dfrac{z_1}{z_2} = \dfrac{(x_1 + i y_1)(x_2 - i y_2)}{(x_2 + i y_2)(x_2 - i y_2)} = \dfrac{x_1 x_2 + y_1 y_2}{x_2^2 + y_2^2} + i\dfrac{x_2 y_1 - x_1 y_2}{x_2^2 + y_2^2} \quad (z_2 \neq 0) $$

    2. 复共轭与模长几何性质

    2.1 复共轭 (Complex Conjugation)

    复数 𝑧 =𝑥 +𝑖𝑦z=x+iyz = x + iy 的 共轭复数 记作 𝑧∗z∗z^* 或 ¯𝑧z¯z，几何上对应于复平面内关于实轴（𝑋XX 轴）的镜像对称反射：

    𝑧∗≡𝑥−𝑖𝑦,𝑖∗=−𝑖z∗≡x−iy,i∗=−iz^* equiv x - iy, quad i^* = -i

    核心代数性质：

    1. 提取实部与虚部：

    $$ x = \operatorname{Re}(z) = \dfrac{z + z^}{2}, \quad y = \operatorname{Im}(z) = \dfrac{z - z^}{2i} $$

    1. 模长平方：

    $$ z z^* = (x + iy)(x - iy) = x^2 + y^2 = |z|^2 \ge 0 $$

    1. 共轭运算的分配律：

    $$ (z_1 \pm z_2)^ = z_1^ \pm z_2^, \quad (z_1 z_2)^ = z_1^ z_2^, \quad \left(\dfrac{z_1}{z_2}\right)^ = \dfrac{z_1*}{z_2} $$

    2.2 复平面阿根图与几何不等式

    复数 𝑧 =𝑥 +𝑖𝑦z=x+iyz = x + iy 与平面直角坐标系中的点 (𝑥,𝑦)(x,y)(x, y) 或以原点为起点的二维矢量 𝒓 =(𝑥,𝑦)r=(x,y)r = (x, y) 存在严格的一一对应映射．

    三角形不等式：对任意两复数 𝑧1,𝑧2z1,z2z_1, z_2，有：

    ||𝑧1|−|𝑧2||≤|𝑧1+𝑧2|≤|𝑧1|+|𝑧2|||z1|−|z2||≤|z1+z2|≤|z1|+|z2|||z_1| - |z_2|| <= |z_1 + z_2| <= |z_1| + |z_2|

    几何与代数证明：
    在复平面阿根图上，矢量 𝑧1,𝑧2z1,z2z_1, z_2 与其和 𝑧1 +𝑧2z1+z2z_1 + z_2 构成平面三角形．几何上三角形任意两边之和大于第三边，两边之差小于第三边．
    代数推导：|𝑧1 +𝑧2|2 =(𝑧1 +𝑧2)(𝑧∗1 +𝑧∗2) =|𝑧1|2 +|𝑧2|2 +(𝑧1𝑧∗2 +𝑧∗1𝑧2) =|𝑧1|2 +|𝑧2|2 +2Re⁡(𝑧1𝑧∗2)|z1+z2|2=(z1+z2)(z1∗+z2∗)=|z1|2+|z2|2+(z1z2∗+z1∗z2)=|z1|2+|z2|2+2Re⁡(z1z2∗)|z_1 + z_2|^2 = (z_1 + z_2)(z_1^* + z_2^*) = |z_1|^2 + |z_2|^2 + (z_1 z_2^* + z_1^* z_2) = |z_1|^2 + |z_2|^2 + 2Re(z_1 z_2^*)．
    因为 Re⁡(𝑤) ≤|𝑤|Re⁡(w)≤|w|Re(w) <= |w|，所以 2Re⁡(𝑧1𝑧∗2) ≤2|𝑧1𝑧∗2| =2|𝑧1||𝑧2|2Re⁡(z1z2∗)≤2|z1z2∗|=2|z1||z2|2Re(z_1 z_2^*) <= 2|z_1 z_2^*| = 2|z_1||z_2|，从而 |𝑧1 +𝑧2|2 ≤(|𝑧1| +|𝑧2|)2|z1+z2|2≤(|z1|+|z2|)2|z_1 + z_2|^2 <= (|z_1| + |z_2|)^2，开方即证．

    2.3 复平面常见轨迹曲线

    利用复数模长方程可极简描述平面解析几何曲线：

    1. 圆周：|𝑧 −𝑧0| =𝑅|z−z0|=R|z - z_0| = R 表示以 𝑧0z0z_0 为圆心、半径为 𝑅RR 的圆周；
    2. 椭圆：|𝑧 −𝑧1| +|𝑧 −𝑧2| =2𝑎|z−z1|+|z−z2|=2a|z - z_1| + |z - z_2| = 2a（2𝑎 >|𝑧1 −𝑧2|2a>|z1−z2|2a > |z_1 - z_2|）表示以 𝑧1,𝑧2z1,z2z_1, z_2 为焦点的椭圆；例如 |𝑧 −3| +|𝑧 +3| =10|z−3|+|z+3|=10|z - 3| + |z + 3| = 10，焦点在 ( ±3,0)(±3,0)(+/- 3, 0)，𝑐 =3,𝑎 =5 ⟹ 𝑏 =√52−32 =4c=3,a=5⟹b=52−32=4c = 3, a = 5 implies b = 5^2 - 3^2 = 4，标准方程为 𝑥225 +𝑦216 =1x225+y216=1x^2/25 + y^2/16 = 1；
    3. 直线/垂直平分线：|𝑧 −𝑧1| =|𝑧 −𝑧2||z−z1|=|z−z2||z - z_1| = |z - z_2| 表示连接 𝑧1,𝑧2z1,z2z_1, z_2 两点线段的中垂线．

    3. 欧拉公式、极坐标与多值辐角

    3.1 欧拉公式 (Euler's Formula)

    数学上最深刻的桥梁——欧拉公式 给出了复指数函数与三角函数的统一：

    𝑒𝑖𝜃=cos⁡𝜃+𝑖sin⁡𝜃(𝜃∈ℝ)eiθ=cos⁡θ+isin⁡θ(θ∈R)e^itheta = costheta + isintheta quad (theta in R)

    当取 𝜃 =𝜋θ=πtheta = pi 时，得到被誉为“最卓越的数学公式”的 欧拉恒等式：

    𝑒𝑖𝜋+1=0eiπ+1=0e^ipi + 1 = 0

    它在极简的代数形式中凝聚了数学分析的五大基石常数：

    6. 物理前沿与后续课程出口

    1. 交流电路复阻抗相量法：

    2. 电动力学与光学复振幅：
      在 电磁学：麦克斯韦方程组与电磁波 中，三维单色平面波写为 𝑬(𝒓,𝑡) =Re⁡[𝑬0𝑒𝑖(𝒌⋅𝒓−𝜔𝑡)]E(r,t)=Re⁡[E0ei(k⋅r−ωt)]E(r, t) = Re[E_0 e^i(k*r-omega t)]，空间散度旋度算子自然转化为代数交叉乘积 ∇ →𝑖𝒌∇→iknabla -> ik；
