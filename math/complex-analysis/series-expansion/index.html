    级数展开与奇点

    物理问题引入：当函数遭遇奇点时会发生什么？

    在理论物理建模中，“奇点（Singularity）”绝不是数学家凭空捏造的抽象病态，而是常常标志着极其关键的物理临界状态或极端相互作用：

    • 点源发散：点电荷所在位置的经典库仑势发散（𝑉 ∝1/𝑟V∝1/rV propto 1/r），质点引力场在原点具有奇点；
    • 共振发散：无阻尼受迫谐振子在外加驱动频率 𝜔ωomega 等于固有频率 𝜔0ω0omega_0 时产生振幅发散（物理共振极点）；
    • 微观量子态的拓扑印记：在量子力学与粒子物理的散射理论中，散射矩阵 𝑆(𝐸)S(E)S(E) 在复能量平面上的极点直接对应了物理稳定束缚态（负能量实轴极点）与有限寿命的共振态粒子（下半平面复数极点）！

    普通泰勒级数（Taylor Series）只能在完全解析的开圆盘内收敛展开，它无法穿透哪怕一个奇点．为了研究包含奇点的区域以及深刻刻画函数在奇点邻域内的渐近行为，物理学家和数学家必须将幂级数向包含负整数幂次的宏大领域推进——这就是 洛朗级数 (Laurent Series)．

    1. 复数项级数与等比级数基石

    1.1 复数列极限与级数绝对收敛

    设复数列 𝑧𝑛 =𝑥𝑛 +𝑖𝑦𝑛zn=xn+iynz_n = x_n + i y_n．𝑧𝑛znz_n 收敛于极限 𝑧0 =𝑥0 +𝑖𝑦0z0=x0+iy0z_0 = x_0 + i y_0 的充分必要条件是其实部与虚部实数列同时收敛：

    lim𝑛→∞𝑥𝑛=𝑥0且lim𝑛→∞𝑦𝑛=𝑦0limn→∞xn=x0且limn→∞yn=y0lim_n -> inf x_n = x_0 quad 且 quad lim_n -> inf y_n = y_0

    对于无穷复数项级数 ∑∞𝑛=1𝑧𝑛∑n=1∞znsum_n=1^inf z_n： - 若正项实级数 ∑∞𝑛=1|𝑧𝑛|∑n=1∞|zn|sum_n=1^inf |z_n| 收敛，则称复级数 ∑∞𝑛=1𝑧𝑛∑n=1∞znsum_n=1^inf z_n 绝对收敛； - 绝对收敛保证了级数可以任意调换求和项的次序，且在收敛域内可以逐项微分与逐项积分．

    1.2 几何级数（等比级数）：一切级数展开的母体

    考察无穷复等比级数 ∑∞𝑘=0𝑧𝑘∑k=0∞zksum_k=0^inf z^k．其前 𝑛nn 项部分和为：

    𝑆𝑛=1+𝑧+𝑧2+⋯+𝑧𝑛=1−𝑧𝑛+11−𝑧(𝑧≠1)Sn=1+z+z2+⋯+zn=1−zn+11−z(z≠1)S_n = 1 + z + z^2 + dots + z^n = 1 - z^n+11 - z quad (z != 1)

    当 |𝑧| <1|z|<1|z| < 1 时，|𝑧𝑛+1| =|𝑧|𝑛+1 →0|zn+1|=|z|n+1→0|z^n+1| = |z|^n+1 -> 0；当 |𝑧| ≥1|z|≥1|z| >= 1 时通项不趋于 0 发散．因此：

    ∞∑𝑘=0𝑧𝑘=11−𝑧(|𝑧|<1)∑k=0∞zk=11−z(|z|<1)sum_k=0^inf z^k = 11 - z quad (|z| < 1)

    此公式是后续推导泰勒定理、洛朗定理与部分分式展开不可替代的代数核．

    2.2 收敛半径的几何意义

    3. 初等超越函数的泰勒展开技巧

    在物理实战中，极少通过直接计算 𝑛nn 阶微商来求泰勒级数，通常采用逐项求导、逐项积分与间接代换．

    经典初等函数展开精选
    1. 对数函数核 ln⁡1+𝑧1−𝑧ln⁡1+z1−zln1+z/1-z 逐项积分：
