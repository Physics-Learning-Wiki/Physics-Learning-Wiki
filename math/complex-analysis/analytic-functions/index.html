    解析函数与柯西-黎曼条件

    物理问题引入：为什么复可微会自动导出拉普拉斯方程？

    在多元实数微积分中，即使一个二元实函数 𝑢(𝑥,𝑦)u(x,y)u(x, y) 在某点的所有偏导数均存在，甚至方向导数均存在，它也可能在临近区域表现出不连续等极度病态的行为． 然而，在复变函数中，只要我们对复变函数：

    𝑓(𝑧)=𝑢(𝑥,𝑦)+𝑖𝑣(𝑥,𝑦)f(z)=u(x,y)+iv(x,y)f(z) = u(x, y) + i v(x, y)

    提出看似平淡无奇的要求——复可微（Complex Differentiable），一系列震撼的分析学奇迹就会随之发生：

    1. 实部与虚部自动满足二维拉普拉斯方程：

    $$ \nabla^2 u = \dfrac{\partial^2 u}{\partial x^2} + \dfrac{\partial^2 u}{\partial y^2} = 0, \quad \nabla^2 v = \dfrac{\partial^2 v}{\partial x^2} + \dfrac{\partial^2 v}{\partial y^2} = 0 $$

    1. 等值线簇处处正交：曲线族 𝑢(𝑥,𝑦) =𝐶1u(x,y)=C1u(x, y) = C_1 与 𝑣(𝑥,𝑦) =𝐶2v(x,y)=C2v(x, y) = C_2 在复平面上凡相交处切线必定互相垂直；
    2. 一阶可微自动保证无穷阶光滑：不存在“一阶可导但二阶导数不存在”的实分析尴尬局面．

    这正是为什么复分析天然就是二维静电场（等势线与电力线正交且空间无源电势满足 ∇2𝜙 =0∇2ϕ=0nabla^2 phi = 0）与二维无旋不可压缩流体（速度势与流函数正交）最完美的数学模型．

    1. 复导数严格定义与严苛性

    设区域 𝐷 ⊂ℂD⊂CD subset C 为复平面的开集，𝑓(𝑧)f(z)f(z) 是定义在 𝐷DD 上的单值复变函数．若对于 𝑧0 ∈𝐷z0∈Dz_0 in D，差商极限：

    𝑓′(𝑧0)=limΔ𝑧→0𝑓(𝑧0+Δ𝑧)−𝑓(𝑧0)Δ𝑧f′(z0)=limΔz→0f(z0+Δz)−f(z0)Δzf'(z_0) = lim_Delta z -> 0 f(z_0 + Delta z) - f(z_0)Delta z

    存在且唯一，则称 𝑓(𝑧)f(z)f(z) 在点 𝑧0z0z_0 可导 (Differentiable)（或可微）．

    注意：极限方向的任意性与路径独立性

    在实数轴上一元极限只有从左侧（Δ𝑥 →0−Δx→0−Delta x -> 0^-）和从右侧（Δ𝑥 →0+Δx→0+Delta x -> 0^+）两个逼近方向；
    而在复平面上，增量 Δ𝑧 =Δ𝑥 +𝑖Δ𝑦 =|Δ𝑧|𝑒𝑖𝛼Δz=Δx+iΔy=|Δz|eiαDelta z = Delta x + iDelta y = |Delta z|e^ialpha 能够以任意辐角、沿任意连续曲线从四面八方向原点逼近！
    要求极限值对所有可能的趋近路径、所有方向完全无关且严格相等，构成了对函数实部与虚部的一组极强约束——柯西-黎曼条件 (Cauchy-Riemann Conditions)．

    2. 柯西-黎曼条件 (Cauchy-Riemann Conditions)

    2.1 直角坐标下的推导

    设 𝑓(𝑧) =𝑢(𝑥,𝑦) +𝑖𝑣(𝑥,𝑦)f(z)=u(x,y)+iv(x,y)f(z) = u(x, y) + iv(x, y) 在点 𝑧zz 处复可导．根据定义，极限与趋向路径无关：

    1. 沿平行于实轴方向逼近（令 Δ𝑦 =0,Δ𝑧 =Δ𝑥 →0Δy=0,Δz=Δx→0Delta y = 0, Delta z = Delta x -> 0）：

    $$ f'(z) = \lim_{\Delta x \to 0} \dfrac{[u(x+\Delta x, y) - u(x, y)] + i[v(x+\Delta x, y) - v(x, y)]}{\Delta x} = \dfrac{\partial u}{\partial x} + i\dfrac{\partial v}{\partial x} $$

    1. 沿平行于虚轴方向逼近（令 Δ𝑥 =0,Δ𝑧 =𝑖Δ𝑦 →0Δx=0,Δz=iΔy→0Delta x = 0, Delta z = iDelta y -> 0）：

    $$ f'(z) = \lim_{\Delta y \to 0} \dfrac{[u(x, y+\Delta y) - u(x, y)] + i[v(x, y+\Delta y) - v(x, y)]}{i\Delta y} = \dfrac{1}{i}\left(\dfrac{\partial u}{\partial y} + i\dfrac{\partial v}{\partial y}\right) = \dfrac{\partial v}{\partial y} - i\dfrac{\partial u}{\partial y} $$

    两式必须恒等，实部与虚部分别对应相等，即得到著名的 柯西-黎曼方程（C-R 条件）：

    𝑓(𝑧)=(3𝑥2𝑦−𝑦3)+𝑖(−𝑥3+3𝑥𝑦2)+𝐶=−𝑖(𝑥+𝑖𝑦)3+𝐶=−𝑖𝑧3+𝐶f(z)=(3x2y−y3)+i(−x3+3xy2)+C=−i(x+iy)3+C=−iz3+Cf(z) = (3x^2 y - y^3) + i(-x^3 + 3xy^2) + C = -i(x + iy)^3 + C = -i z^3 + C
    例题 3：非初等根号虚部的解析函数重构

    已知解析函数虚部为 𝑣(𝑥,𝑦) =√−𝑥+√𝑥2+𝑦2v(x,y)=−x+x2+y2v(x, y) = -x + x^2 + y^2，求 𝑓(𝑧)f(z)f(z)．
    极坐标巧妙解法：令 𝑥 =𝑟cos⁡𝜃,𝑦 =𝑟sin⁡𝜃x=rcos⁡θ,y=rsin⁡θx = rcostheta, y = rsintheta（取 𝑟 >0,0 <𝜃 ≤𝜋r>0,0<θ≤πr > 0, 0 < theta <= pi）：

    𝑣=√−𝑟cos⁡𝜃+𝑟=√2𝑟sin2⁡𝜃2=√2𝑟sin⁡𝜃2v=−rcos⁡θ+r=2rsin2⁡θ2=2rsin⁡θ2v = -rcostheta + r = 2rsin^2theta/2 = 2rsintheta/2

    由极坐标 C-R 条件：

    𝜕𝑢𝜕𝑟=1𝑟𝜕𝑣𝜕𝜃=1√2𝑟cos⁡𝜃2⟹𝑢(𝑟,𝜃)=√2𝑟cos⁡𝜃2+𝐶∂u∂r=1r∂v∂θ=12rcos⁡θ2⟹u(r,θ)=2rcos⁡θ2+Cd ud r = 1rd vd theta = 12rcostheta/2 implies u(r, theta) = 2rcostheta/2 + C

    合成解析函数：

    𝑓(𝑧)=𝑢+𝑖𝑣=√2𝑟(cos⁡𝜃2+𝑖sin⁡𝜃2)+𝐶=√2𝑧+𝐶(𝐶∈ℝ)f(z)=u+iv=2r(cos⁡θ2+isin⁡θ2)+C=2z+C(C∈R)f(z) = u + iv = 2rleft(costheta/2 + isintheta/2right) + C = 2z + C quad (C in R)

    6. 物理模型：静电复势与流体正交网格

    在二维无源静电场中，电势 𝜙(𝑥,𝑦)ϕ(x,y)phi(x, y) 满足二维拉普拉斯方程 ∇2𝜙 =0∇2ϕ=0nabla^2 phi = 0．令其为一个解析函数的实部：

    𝑊(𝑧)=𝜙(𝑥,𝑦)+𝑖𝜓(𝑥,𝑦)W(z)=ϕ(x,y)+iψ(x,y)W(z) = phi(x, y) + i psi(x, y)

    称 𝑊(𝑧)W(z)W(z) 为 复势 (Complex Potential)． - 实部曲线族 𝜙(𝑥,𝑦) =𝐶1ϕ(x,y)=C1phi(x, y) = C_1 是 等势线； - 虚部曲线族 𝜓(𝑥,𝑦) =𝐶2ψ(x,y)=C2psi(x, y) = C_2 是 电力线； - 梯度点积计算表明：

    $$ \nabla\phi \cdot \nabla\psi = \dfrac{\partial\phi}{\partial x}\dfrac{\partial\psi}{\partial x} + \dfrac{\partial\phi}{\partial y}\dfrac{\partial\psi}{\partial y} = \left(\dfrac{\partial\psi}{\partial y}\right)\left(\dfrac{\partial\psi}{\partial x}\right) + \left(-\dfrac{\partial\psi}{\partial x}\right)\left(\dfrac{\partial\psi}{\partial y}\right) \equiv 0 $$

    等势线与电力线在任意点严格正交！ 此外，复电场强度矢量可直接通过对复势求导给出：

    𝐸𝑥−𝑖𝐸𝑦=−d𝑊d𝑧Ex−iEy=−dWdzE_x - i E_y = -dWdz

    将实向量分析的求梯度运算直接升华为简单的单变量一阶复求导．在二维理想无旋不可压缩流体中，𝜙ϕphi 为速度势，𝜓ψpsi 为流函数，复速度为 𝑣𝑥 −𝑖𝑣𝑦 =d𝑊d𝑧vx−ivy=dWdzv_x - iv_y = dWdz，构成了机翼升力计算（茹科夫斯基变换）的理论基石．
