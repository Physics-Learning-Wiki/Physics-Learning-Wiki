    首页

    Physics-Learning-Wiki 致力于为物理爱好者与大学本科生提供一条可持续扩展的系统化物理学习主线．我们当前优先解决的问题不是「条目够不够多」，而是「你能不能顺着学下去」．

    建议先从这里开始

    1. 阅读 学习路线总览，先确定自己的阶段和主线顺序．
    2. 进入对应学科的导学页，例如 经典力学、热学与统计物理 或 电磁学．
    3. 遇到公式、符号或方法障碍时，回到 数学工具、实验物理 与 计算物理与工具 补足支撑知识．
    4. 如果你想参与贡献，可以阅读 如何参与；如果你不会使用 GitHub，也可以直接发送稿件到 submit@folderrewind.top．
    贡献你的物理知识

    不需要 GitHub 账号！直接访问 投稿页面 分享你的笔记、勘误或建议．
    每一份贡献都会被署名记录在 贡献者墙 上．

    本站的组织方式

    主线学习模块

    • 数学工具

      作为物理学习的基础支撑，微积分、线性代数与特殊函数与主线同步推进．

    • 经典力学

      建立质点运动、相互作用、守恒律与动力学建模的第一层坚实框架．

    • 热学与统计物理

      理解宏观物态、热力学定律的方向性以及微观状态的统计描述．

    • 电磁学

      从静电场、恒定磁场到麦克斯韦方程组，重建场与相互作用图景．

    • 光学

      连接几何成像、波动干涉与衍射偏振，走向现代物理光学基础．

    • 近代物理

      迈向狭义与广义相对论、量子力学基础与微观粒子物理观念．

    并行支撑模块

    • 实验物理

      帮助理解测量、误差、数据处理与真实实验物理场景．

    • 计算物理与工具

      掌握 LaTeX 写作、Python 科学计算、数值模拟与科学绘图能力．

    • 术语表

      用于快速回顾核心物理定义、符号约定与常用名词．

    专题支线

    • 竞赛相关：面向竞赛与专题训练，但不再作为全站主入口．
    • 知识小测：通过分级自测题目巩固物理概念与公式运用．
    • 题库、参考资料与专题页会逐步补齐，用于第二遍学习和强化训练．

    如何使用本站

    1. 先看导学页，再进入正文页，不要直接在目录里跳着读．
    2. 每读一页都先回答三个问题：它在解决什么问题、它依赖什么先修、它学完以后能干什么．
    3. 如果某一页暂时读不动，不要硬啃，先回到主线前面的页面或支撑模块补足背景．
    4. 竞赛、开放题和进阶证明建议放在完成主线第一遍之后再集中处理．

    欢迎投稿与协作

    我们欢迎三类贡献：

    • 修正错误、补充引用和改善表述．
    • 撰写完整页面或重构已有页面．
    • 提交半成品笔记、提纲、讲义、课堂整理或题目解析，由编辑组协助整理．

    如果你熟悉 GitHub，请走 Pull Request 流程；如果你不熟悉 GitHub，可以直接发送邮件到 submit@folderrewind.top．详细说明见 如何参与 与 内容编写指引．
