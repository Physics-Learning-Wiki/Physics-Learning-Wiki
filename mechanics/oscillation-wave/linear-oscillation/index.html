    线性振动

    线性振动是物理学中一种重要的运动形式，广泛存在于各种物理系统中．它通常指系统在平衡位置附近的小幅度振动，其运动方程可以用线性微分方程描述．

    简单谐振动

    如果某一物量在平衡点附近往复振动，且随时间的变化是余弦（或正弦）的函数形式，我们就把这种振动称为简谐振动．

    运动方程推导

    简单谐振动是最基本的线性振动形式，其运动方程为：

    𝑑2𝑥𝑑𝑡2+𝜔2𝑥=0d2xdt2+ω2x=0d^2xdt^2 + omega^2 x = 0

    这一方程可以通过牛顿第二定律推导得到．例如，对于一个质量为 𝑚mm 的物体，受到的回复力 𝐹FF 满足胡克定律：

    𝐹=−𝑘𝑥F=−kxF = -kx

    根据牛顿第二定律：

    𝐹=𝑚𝑑2𝑥𝑑𝑡2F=md2xdt2F = md^2xdt^2

    代入回复力表达式：

    𝑚𝑑2𝑥𝑑𝑡2=−𝑘𝑥md2xdt2=−kxmd^2xdt^2 = -kx

    整理得：

    𝑑2𝑥𝑑𝑡2+𝑘𝑚𝑥=0d2xdt2+kmx=0d^2xdt^2 + kmx = 0

    令 𝜔 =√𝑘𝑚ω=kmomega = k/m，即得简单谐振动的运动方程．

    解的形式

    该方程的通解为：

    𝑥(𝑡)=𝐴cos⁡(𝜔𝑡+𝜙)x(t)=Acos⁡(ωt+ϕ)x(t) = A cos(omega t + phi)

    其中：

    • 𝐴AA 为振幅，振子离开平衡位置的最大位移的绝对值，由初始条件决定．是求解上述微分方程时引入的常量；
    • 𝜙ϕphi 为初相位，初始时刻振子的相位，由初始条件决定．是求解上述微分方程时引入的常量；
    • 𝜔ωomega 为角频率（圆频率），在简谐振动的几何表示中，表示旋转矢量的角速度；
    • 𝑥xx 为位移，表示振子相对于平衡位置的偏移量．
    例 1

    设一个质量为 𝑚mm 的物体连接在弹簧上，弹簧劲度系数为 𝑘kk．求该系统的角频率 𝜔ωomega 及其运动方程．

    解：
    易得运动方程为：

    𝑑2𝑥𝑑𝑡2+𝑘𝑚𝑥=0d2xdt2+kmx=0d^2xdt^2 + kmx = 0

    角频率：

    𝜔=√𝑘𝑚ω=kmomega = km

    因此，运动方程为：

    𝑥(𝑡)=𝐴cos⁡(√𝑘𝑚𝑡+𝜙)x(t)=Acos⁡(kmt+ϕ)x(t) = A cosleft(kmt + phiright)

    其中 𝐴AA 和 𝜙ϕphi 由初始条件决定．

    例 2

    设一个质量为 𝑚mm 的物体连接在摆绳上，摆长为 𝑙ll．求该单摆系统的角频率 𝜔ωomega 及其运动方程．

    解：

    𝑀=−𝑚𝑔𝑙sin⁡𝜃=𝐼𝛽=𝑚𝑙2𝑑2𝜃𝑑𝑡2M=−mglsin⁡θ=Iβ=ml2d2θdt2M = -mglsintheta = Ibeta = ml^2 d^2dt^2

    对于小角度摆动，sin⁡𝜃 ≈𝜃sin⁡θ≈θsintheta ~ theta，单摆的运动方程为：

    𝑑2𝜃𝑑𝑡2+𝑔𝑙𝜃=0d2θdt2+glθ=0d^2dt^2 + gltheta = 0

    角频率：

    𝜔=√𝑔𝑙ω=glomega = gl

    因此，运动方程为：

    𝜃(𝑡)=𝐴cos⁡(√𝑔𝑙𝑡+𝜙)θ(t)=Acos⁡(glt+ϕ)theta(t) = A cosleft(glt + phiright)

    其中 𝐴AA 和 𝜙ϕphi 由初始条件决定．

    小角度近似

    在单摆的例子中，我们使用了小角度近似 sin⁡𝜃 ≈𝜃sin⁡θ≈θsintheta ~ theta．这一近似仅在摆动角度较小时成立（通常小于约 10 度）．对于较大的摆动角度，运动方程将变得非线性，不能再用简单谐振动的形式描述．

    简谐振动的判断

    并非所有往复振动都是简谐振动．简谐振动要求回复力与位移成正比且方向相反，即满足 胡克定律的形式．对于非线性系统或大幅度振动，运动方程可能不再是线性的，不能用简谐振动的形式描述．我们往往也可以通过得到相应的 特征微分方程 来判断振动是否为简谐振动．

    周期与频率

    振动的周期 𝑇TT 和频率 𝑓ff 分别为：

    𝑇=2𝜋𝜔,𝑓=1𝑇=𝜔2𝜋.T=2πω,f=1T=ω2π.T = 2omega, quad f = 1T = 2pi.

    相位

    振动的相位 𝜃θtheta 定义为：

    𝜃=𝜔𝑡+𝜙.θ=ωt+ϕ.theta = omega t + phi.

    相位表示振动在某一时刻所处的位置状态．规定 0 <𝜃 <2𝜋0<θ<2π0 < theta < 2pi．

    对于两个同频简谐振动，其相位差 Δ𝜃ΔθDelta theta 为：

    Δ𝜃=𝜃1−𝜃2=𝜙1−𝜙2.Δθ=θ1−θ2=ϕ1−ϕ2.Delta theta = theta_1 - theta_2 = phi_1 - phi_2.

    若 Δ𝜃 =0Δθ=0Delta theta = 0，则两振动 同相，若 Δ𝜃 =𝜋Δθ=πDelta theta = pi，则两振动 反相． 若 0 <Δ𝜃 <𝜋0<Δθ<π0 < Delta theta < pi，则称 𝑥1x1x_1 比 𝑥2x2x_2 超前，若 𝜋 <Δ𝜃 <2𝜋π<Δθ<2πpi < Delta theta < 2pi，则则称 𝑥1x1x_1 比 𝑥2x2x_2 落后．

    动能与势能

    总能量在振动过程中保持不变，动能和势能在振动过程中相互转化．

    简正模

    在多自由度系统中，线性振动可以分解为若干个独立的简正模（Normal Modes）．每个简正模对应一个特定的频率和振动模式，系统的总振动可以看作这些简正模的叠加．

    阻尼振动

    运动方程

    当系统受到阻尼力作用时，振动会逐渐衰减，其运动方程为：

    𝑑2𝑥𝑑𝑡2+2𝛽𝑑𝑥𝑑𝑡+𝜔2𝑥=0d2xdt2+2βdxdt+ω2x=0d^2xdt^2 + 2beta dxdt + omega^2 x = 0

    其中 𝛽βbeta 为阻尼系数，描述阻尼的强弱．

    解的形式

    根据阻尼的大小，解的形式不同：

    1. 欠阻尼振动（𝛽 <𝜔β<ωbeta < omega）：
    𝑥(𝑡)=𝐴𝑒−𝛽𝑡cos⁡(𝜔𝑑𝑡+𝜙)x(t)=Ae−βtcos⁡(ωdt+ϕ)x(t) = A e^-beta t cos(omega_d t + phi)

    其中 𝜔𝑑 =√𝜔2−𝛽2ωd=ω2−β2omega_d = omega^2 - beta^2 为阻尼振动的角频率．

    强迫振动

    运动方程

    当系统受到周期性外力作用时，其运动方程为：

    𝑑2𝑥𝑑𝑡2+2𝛽𝑑𝑥𝑑𝑡+𝜔2𝑥=𝐹0cos⁡(Ω𝑡)d2xdt2+2βdxdt+ω2x=F0cos⁡(Ωt)d^2xdt^2 + 2beta dxdt + omega^2 x = F_0 cos(Omega t)

    其中：

    • 𝐹0F0F_0 为外力的振幅；
    • ΩΩOmega 为外力的角频率．

    稳态解

    稳态解为：

    𝑥(𝑡)=𝐴cos⁡(Ω𝑡−𝛿)x(t)=Acos⁡(Ωt−δ)x(t) = A cos(Omega t - delta)

    其中：

    • 𝐴 =𝐹0√(𝜔2−Ω2)2+(2𝛽Ω)2A=F0(ω2−Ω2)2+(2βΩ)2A = F_0/(omega^2 - Omega^2)^2 + (2betaOmega)^2 为稳态振幅；
    • 𝛿 =arctan⁡(2𝛽Ω𝜔2−Ω2)δ=arctan⁡(2βΩω2−Ω2)delta = arctanleft(2betaOmega/omega^2 - Omega^2right) 为相位差．

    共振现象

    当驱动力频率接近系统的固有频率时，即 Ω ≈𝜔Ω≈ωOmega ~ omega，系统的振幅达到最大值，称为 共振．

    共振条件下的振幅为：

    𝐴res=𝐹02𝛽𝜔Ares=F02βωA_res = F_02betaomega
